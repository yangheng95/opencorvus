# Selection guidance

Select this squad for an authorized, time-bounded mission evidence set involving recorded telemetry, spacecraft modes and configuration, ground-contact opportunities, data production and downlink resources, controlled procedure versions, rehearsals, verification evidence, or anomaly timelines. Supply spacecraft and mission-phase identity, Operations Database and procedure versions, source locators, time-system mappings, data cutoff, accountable owner, and named qualified reviewers.

Do not select it for aircraft maintenance, telecom service assurance, geospatial imagery analysis, live orbit determination, commanding, pass booking, collision avoidance, frequency coordination, or emergency response. Stop when source/configuration/time correlation is unverifiable or when the requested output would operate a spacecraft or ground asset.

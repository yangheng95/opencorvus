# Cloud FinOps Qualified-review Pack

## Package identity and provenance

Record `artifact_id`, package/version/hash, review scope and cutoff, provider/account/subscription/project IDs, billing/service/usage periods, currencies and quantity units, source/schema/contract/allocation/metric/forecast versions and dates, branch artifact hashes, owner, qualified FinOps/engineering/finance/procurement/accounting/tax/security/service reviewers, applicability/jurisdiction, assumptions, uncertainty/confidence, privacy/license boundary, status, `decision_not_made`, `outcome_unknown` and `stop_or_escalation`.

This is a join of frozen evidence, not a budget, accounting close, tax opinion, purchase, cloud change, vendor request, savings approval or value decision.

## Required branch closure

1. Cost/usage/billing branch: baseline and ledger hashes, source totals, reconciliations, schema/currency/sign/time issues and unresolved residuals.
2. Allocation/unit-economics branch: rule and metric versions, cost pools, drivers, numerators, denominators, residuals, formulas, windows and uncertainty.
3. Forecast/commitment/optimization branch: budget/forecast versions, scenario assumptions, commitment terms, utilization/coverage evidence, candidate states and current-source needs.
4. Anomaly/governance/value branch: anomaly definition and decomposition, event correlation limits, policy/control/exception ownership and value-link evidence.

## Joined claim and contradiction table

For each review statement, record claim ID, classification as source fact/observation/calculation/assumption/hypothesis/estimate/approved decision/implemented change/observed outcome/unknown, exact source row, formula, unit, cutoff, reviewer and uncertainty. Reconcile identity, period, currency, cost definition, allocation, metric, forecast, commitment and anomaly conflicts without choosing a convenient source.

Separate modeled potential from approved, implemented, observed and finance-validated value. Preserve unallocated cost and unexplained reconciliation residual as explicit signals. A provider console value, tag, recommendation or anomaly alert is not self-validating evidence.

## Decision and stop matrix

List every open data need, candidate decision, approval system, accountable owner and qualified reviewer. Stop for source authorization gaps, mixed account/currency/period, incompatible schema, absent allocation/metric authority, stale commitment terms, unsupported anomaly threshold, confidential data outside scope, active incident or ambiguous external effect.

`decision_not_made` enumerates no budget, purchase/exchange/cancellation, resize/stop/delete/deploy, tag/policy, accounting, tax, vendor, savings or value decision. `outcome_unknown` remains until authoritative provider and finance records reconcile any ambiguous external effect.

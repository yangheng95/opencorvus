# FinOps Anomaly Governance and Value Analyst

## Input contract

Require anomaly ID and detector/query version, comparison baseline, dimensions, threshold authority, detection/event window, reconciled cost/usage rows, deployments/incidents/demand/contract event IDs, governance policy/control/exception versions, approved business/service metrics, cutoff, owner and qualified FinOps, service, security, finance and business reviewers. Load `cloud-finops-cost-governance/shared/method`. Do not accept an alert screenshot, correlation or provider recommendation as a causal finding.

## Domain method

Freeze anomaly definition and decompose the observed cost change into price, quantity, mix, scope, allocation, currency, credit/tax, timing and unexplained residual where the data permits. Link surrounding changes only by stable identifiers and time evidence while retaining alternatives and counterevidence. Map policies and controls by ID/version/scope, execution system, owner, exception and review state without enforcing them. Link cost to an approved value metric using explicit numerator, denominator, formula, cohort and cutoff; separate correlation from causal and financial conclusions.

## Evidence output

Populate anomaly, control, exception and candidate-value rows in `commitment-optimization-anomaly-evidence-register.md`. Include source locator/version/date/hash, threshold source, quantities/units/currency, baseline, event IDs, decomposition residual, evidence and counterevidence, assumptions, uncertainty, privacy boundary, owner/reviewer, applicability, status, `decision_not_made`, `outcome_unknown` and stop reason. Produce a contradiction list and value-evidence boundary for the join.

## Unknown and stop conditions

Stop for unsupported threshold, mixed account or currency, changing baseline, missing query/configuration, absent event identity, incomplete denominator, stale policy, confidential data outside scope, active security or service incident outside authority, or ambiguous external effect. Do not infer cause from temporal proximity, label an anomaly as waste without evidence, or treat estimated value as realized.

## Authority boundary

Do not change alerts, thresholds, budgets, tags, policies or resources; open or close incidents; contact vendors or business owners; determine fraud/security attribution; post accounting entries; or approve value and savings. This branch records evidence and candidate review states only.

## Qualified human review

Require detector/query owner, service engineering, FinOps, business-metric owner, finance/accounting and where applicable security review. State unexplained residuals, alternative explanations, policy exceptions, denominator gaps and every decision not made. Qualified owners decide anomaly disposition, control changes and value recognition.

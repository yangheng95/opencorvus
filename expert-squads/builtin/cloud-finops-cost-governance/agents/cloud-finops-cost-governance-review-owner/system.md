# Cloud FinOps Cost Governance Review Owner

## Input contract

Require the current successful reports and asset hashes from all four declared roots: billing quality, allocation/unit economics, forecast/commitment/optimization, and anomaly/governance/value. Require common review scope, provider/account identity, periods, currencies, source cutoff, allocation/metric/forecast/contract versions, owner and qualified reviewers. Load `cloud-finops-cost-governance/shared/method`. Refuse partial synthesis, stale branch output or an undeclared replacement branch.

## Domain method

Reconcile stable identities, source versions, billing/service/usage periods, currencies, cost definitions, source totals, allocation pools/drivers/residuals, metric formulas, budgets/forecasts, commitment terms, candidates, anomalies, controls and value links. Preserve incompatible records in a contradiction table. Classify every statement as fact, observation, calculation, assumption, hypothesis, estimate, approved decision, implemented change, observed outcome or unknown. Distinguish gross/modelled potential from finance-validated realized value. Never fill a missing branch or decide which conflicting source is authoritative.

## Evidence output

Complete `cloud-finops-qualified-review-pack.md` with package and branch digests, exact source/row links, formula inventory, reconciliation and residual tables, candidate decisions, contradictions, unknowns, `outcome_unknown`, accountable owners and required qualified reviews. Confirm closure of exactly five core assets. State each purchase, resource, budget, accounting, tax, policy, vendor, savings and value `decision_not_made`. The visible summary must name the evidence cutoff and not duplicate unsupported estimates.

## Unknown and stop conditions

Stop for absent or mismatched branch hashes, mixed account/currency/period, irreconcilable schema or source totals, incomplete allocation/metric formulas, stale commitment terms, unsupported anomaly threshold, confidential data outside scope, active incident, or ambiguous external action. Preserve gaps and route them to named owners; never solve them with remembered prices, inferred rules or convenient totals.

## Authority boundary

Do not buy, exchange or cancel commitments; resize, stop, delete or deploy resources; change tags/policy; create or approve budgets; post entries; determine tax; submit vendor requests; contact providers; approve savings/value; or represent the pack as audit assurance. This join controls evidence consistency only.

## Qualified human review

Require FinOps, engineering/service, procurement, finance/accounting and relevant tax/security/business-metric owners to review their domains. Identify which reviewer must accept each source, formula, candidate and unresolved conflict. Conclude only that the evidence pack is ready or not ready for qualified review; never issue the professional or operational decision itself.

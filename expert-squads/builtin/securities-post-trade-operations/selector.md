# Selection Guidance

Select for trade capture/allocation/confirmation, clearing/netting, custody/DVP/RVP, settlement and fail/break reconciliation.

Select only when the task supplies or can explicitly mark unknown the governing scope, source versions, cutoff/effective dates, units and denominators, accountable owner, qualified reviewers, and requested decision. Run all four roots; the explicit join reconciles their evidence and contradictions.

Do not select this Squad to perform live operations, external submissions, regulated decisions, professional sign-off, destructive handling, credentialed access, or changes to production systems. Stop and name the authorized human when authority, evidence identity, applicability, privacy or safety boundaries are unclear.

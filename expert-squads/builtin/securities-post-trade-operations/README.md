# Securities Post-Trade Operations

Trade capture, clearing, custody, settlement and break evidence joined for qualified post-trade review.

Run the four zero-dependency professional branches concurrently. Dispatch `securities-post-trade-operations-review-owner` only after all four reports exist. The scheduler and every worker project the single package Skill `securities-post-trade-operations/shared/method`.

This package prepares source-addressable evidence for qualified review. It does not execute external or production actions, make regulated or professional determinations, or convert missing evidence into assumed facts. See `selector.md` for scope and stop conditions.

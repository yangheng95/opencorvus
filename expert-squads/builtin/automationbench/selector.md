# Selection

Use this squad when the Task is an AutomationBench business request and the project has
the harness-owned `automationbench` MCP connection. Preserve the complete original
request, including its source-value, destination, formatting and preservation constraints.
Select `review-execute-verify`. A missing environment is a concrete blocker, not permission to
simulate tool results or use another service. Do not select this squad for real external accounts.

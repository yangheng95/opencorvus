# Digital Forensics Incident Investigation

An evidence-first digital-forensics squad. Four independent roots freeze authority and preservation, examine supplied endpoint/memory/disk evidence, correlate network/cloud/identity artifacts, and test event timelines and competing hypotheses. An explicit owner joins their records without live access, remediation, attribution or legal conclusions.

The package projects one Skill, `digital-forensics-incident-investigation/shared/method`, to the scheduler and every worker and owns exactly five controlled assets. It is a bounded Apache-2.0 adaptation with exact provenance and license closure in `skills/method/references`.

Select only for expressly authorized evidence already acquired by qualified personnel. It cannot collect, query or alter systems or evidence, extract credentials, run malware, contain an incident, attribute an actor, determine admissibility or contact external parties.

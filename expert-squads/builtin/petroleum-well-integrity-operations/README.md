# Petroleum Well Integrity Operations

An evidence-first petroleum-well integrity squad. Four zero-dependency specialists freeze well identity and design envelope, trace drilling/completion barrier verification, organize production surveillance, and examine intervention/change/anomaly evidence. An explicit evidence owner joins them without declaring a barrier valid or authorizing operations.

The package projects one local clean-room Skill, `petroleum-well-integrity-operations/shared/method`, to the scheduler and every worker and owns exactly five controlled assets. It uses current official regulatory and safety-method sources recorded in `skills/method/references/source-provenance.md`; no text from the rejected unlicensed archived repository was copied.

Select for a specifically identified well and supplied operator evidence. Never use for live well control, BOP/valve/pressure/kill/cement instructions, MAASP or operating-limit calculation, shutdown/restart/abandonment decisions, permits, waivers or compliance declarations.

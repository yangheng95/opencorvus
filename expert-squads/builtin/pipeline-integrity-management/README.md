# Pipeline Integrity Management

This package prepares regulated pipeline segment/configuration, threat/data, assessment/anomaly, excavation/repair, and management-of-change evidence for qualified review. Three independent roots converge into one explicit integrity review owner.

It does not operate a pipeline, classify threats, set pressure or response criteria, issue field instructions, authorize excavation/repair, return a segment to service, make emergency decisions, or declare regulatory compliance. The package is clean-room and preserves exact operator, source, procedure, model, unit, cutoff, reviewer, and uncertainty evidence.

# Light Selection

Select Light when the operator wants an answer, consultation, plan, comparison, read-only investigation, or a minimal set of clarifying questions and does not want this Task to implement or operate anything.

Light declares no binding virtual workflow. The Orchestrator may directly dispatch one or many `light-planner` and `light-investigator` Sessions according to the independent question and evidence partitions. Multiple Sessions may reuse either Agent identity concurrently; do not create numbered permanent identities or serialize independent work.

Do not select Light for file changes, code implementation, document production, browser or desktop operation, deployment, external communication, transactions, approvals, or any other external effect. When a request mixes advice with execution, keep the advisory phase separate and bind the execution phase to the Expert Squad that owns the actual delivery.

# Selection guidance

Select for equipment and software configuration, acceptance or commissioning evidence, reference dosimetry, periodic machine QA, treatment-planning-system verification, patient-specific QA records, controlled changes, incident evidence or independent audit readiness.

Do not select to prescribe, plan treatment, operate equipment, authorize beam-on, change a device, choose tolerances, classify a medical event or return a system to service. Use only for evidence preparation before qualified medical-physics review.

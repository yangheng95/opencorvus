# Browser Research & Acceptance

One Planner defines observable criteria, page boundaries, permitted interactions, evidence types, and stop conditions. The Evidence Observer and Acceptance Reviewer then execute independent real-page partitions in parallel; both consume only the plan and personally capture the evidence needed for their result.

The package method adapts bounded observation and safety ideas from Tencent BrowserSkill at the pinned MIT-licensed revision recorded in its references. It does not embed BrowserSkill, require its CLI, or treat static inspection as browser acceptance.

Authentication challenges, one-time codes, payments, destructive actions, and permission expansion remain user-owned. UI acceptance uses real pages, interactions, diagnostics, and fresh screenshots, never UI automation or missing-evidence inference.

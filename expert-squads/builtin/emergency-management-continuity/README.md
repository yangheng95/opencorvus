# Emergency Management and Continuity

All-hazards assumptions, essential-function continuity, incident resources and communications, and exercise-improvement evidence converge into an accountable readiness pack.

Run four root branches independently, then dispatch the readiness owner only after all four versioned reports exist. The scheduler and every worker use `emergency-management-continuity/shared/method`; the Skill ships five dedicated planning, continuity, coordination and improvement assets.

This package is planning support, not a live emergency authority. It never declares or activates an incident, issues evacuation, shelter or life-safety instructions, assumes Incident Command System authority, dispatches resources, sends public warnings, changes approved plans or contact systems, or certifies readiness. Require the Authority Having Jurisdiction, incident commander, emergency manager, continuity owner, public information, accessibility, safety, medical, facilities, information-technology, privacy and legal review.

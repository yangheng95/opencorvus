# Product Video Production selection

Select this Squad when the operator has identified the product, audience, target channel, approximate duration, approved claims or source material, and production constraints.

Use the `product-video-production-handoff` workflow for a complete brief-to-review path. Narrative and visual planning deliberately run in parallel only after the brief is frozen. Their results converge at the delivery reviewer.

Do not select this package for an unbounded brand strategy request, unsupported factual claims, guaranteed engagement, or a request that requires actual rendering when no compatible media tool is granted to the active Task.

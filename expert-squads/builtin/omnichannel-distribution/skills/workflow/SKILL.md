# Omnichannel Distribution workflow

Use only omnichannel-delivery-pack. Every node runs exactly once. Channel research and compliance are parallel; adaptation and measurement are parallel after both inputs; distribution synthesis joins them; review depends only on the synthesis; delivery depends only on review. Every handoff is a typed Artifact discovered, completely read, and selected by its consumer. The delivery owner writes, rereads, verifies, and commits the complete bundle; when merge_back is available it requires a merged result, completely reads every final file from the exact immutable returned primary_head, passes that same value as artifact_snapshot.source_commit, and publishes the bundle and matching presentation from those commit bytes without any post-merge write or Git mutation. A primary-project run without merge_back omits source_commit and snapshots the reread bundle directly.

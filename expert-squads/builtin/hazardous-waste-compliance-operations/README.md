# Hazardous Waste Compliance Operations

This package prepares auditable waste-stream determination, generator/accumulation, and manifest-to-disposition evidence. Three zero-dependency analysts work in parallel and an explicit review owner joins their outputs.

The package is clean-room authored from public EPA, eCFR, applicable state-program, and operator-controlled sources. It does not reproduce protected standards or hard-code jurisdiction-dependent thresholds. It does not determine law, assign waste codes or generator status, handle material, sign or submit a manifest, direct a shipment, authorize treatment/disposal, or replace emergency responders, a qualified environmental professional, laboratory, facility environmental health and safety owner, transporter/receiving facility, legal counsel, or regulator.

The only package Skill is `hazardous-waste-compliance-operations/shared/method`. All scheduler and worker projections use that exact reference. See the Skill references for primary-source and rejected-candidate evidence.

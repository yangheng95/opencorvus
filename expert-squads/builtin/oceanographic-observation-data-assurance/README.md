# Oceanographic Observation Data Assurance

This package prepares a bounded oceanographic observation and data assurance pack. Four independent roots cover platform/instrument metadata, profile and time-series quality control, coordinate/format/provenance, and cross-platform validation. The explicit review owner joins them while retaining calibration lineage, raw/adjusted/derived separation, flag provenance, coordinate semantics, collocation uncertainty, and disagreements.

The method includes a bounded BSD-3-Clause adaptation of UW-SSEC Xarray guidance for labeled multidimensional data and clean-room oceanographic governance derived from current primary sources. It does not operate platforms or instruments, change calibrations, overwrite flags, delete or publish data, declare a truth source, issue a forecast/warning/navigation instruction, or make hydrographic, marine-safety, environmental-health, or compliance determinations.

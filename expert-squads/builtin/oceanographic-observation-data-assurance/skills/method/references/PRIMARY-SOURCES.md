# Oceanographic primary sources

Use current authoritative sources to identify vocabulary and evidence provenance; do not copy manuals or hardcode their thresholds.

- U.S. IOOS QARTOD project and current manuals: https://ioos.noaa.gov/project/qartod/
- Global Ocean Observing System Essential Ocean Variables: https://goosocean.org/what-we-do/framework/essential-ocean-variables/
- CF Metadata Conventions: https://cfconventions.org/
- NOAA National Centers for Environmental Information metadata guidance: https://www.ncei.noaa.gov/resources/metadata
- NOAA World Ocean Database product identity and provenance: https://www.ncei.noaa.gov/metadata/geoportal/rest/metadata/item/gov.noaa.nodc%3ANCEI-WOD/html

For each source, record publisher/authority, title/manual, variable or method scope, edition/version, publication/effective date, URL or controlled locator, access date, applicability, license/access restriction and local operator approval. Use only the project-selected current manual and test thresholds. Suspect or failed flags require explicit human review; the Skill does not overwrite or publish them.

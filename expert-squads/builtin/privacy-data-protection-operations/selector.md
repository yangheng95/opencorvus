# Selection guidance

Select this squad for an authorized, date-locked evidence set involving processing inventories and data flows, privacy impact assessment preparation, data-subject request intake/source-search records, retention/deletion/hold conflicts, or personal-data incident chronology and scope. Supply organization roles, jurisdictions as questions for counsel, system/source versions, request or incident scope, data cutoff, minimization rules, owner, and qualified reviewers.

Do not select it to replace commercial legal work, cybersecurity containment, or data-engineering operations. Stop before legal conclusions, production queries/exports/disclosures/deletions, identity verification actions, hold changes, incident containment, notification decisions, or external contact.

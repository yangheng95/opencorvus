# Office Delivery selection

Select this package when the user needs a finished office artifact, not only advice or raw analysis. Preserve the requested formats, editable-source requirement, audience, decision, source inputs, brand or layout constraints, formulas, accessibility needs, output language, and delivery deadline.

Use `planned-office-delivery` exactly as declared. The Planner runs first; Source Analyst and Builder then execute independent partitions. Accept the deliverable only after the Builder opens or renders every applicable page, slide, and populated sheet region; parsing, type checking, or file existence alone is not visual acceptance.

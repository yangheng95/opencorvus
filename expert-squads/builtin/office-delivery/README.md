# Office Delivery

Office Delivery creates editable, evidence-backed documents, spreadsheets, presentations, PDFs, or coordinated packs. One Planner fixes the source boundary, document structure, formatting system, worker ownership, and acceptance. Source Analyst and Delivery Builder then work in parallel from that plan and the original inputs.

The Builder owns editable sources, canonical exports, reopen/render checks, fresh visual inspection, and repair. The Analyst independently validates source facts, citations, calculations, and unknowns. File existence or parsing alone is never rendered acceptance.

The package-local method is clean-room OpenCorvus work; no third-party Office Skill was copied without package-wide license evidence.

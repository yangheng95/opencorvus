# Office Delivery

Office Delivery creates a new editable, evidence-backed PPTX presentation. One Planner fixes the source boundary, slide structure, formatting system, worker ownership, and acceptance. Source Analyst and Delivery Builder then work in parallel from that plan and the original inputs.

The Builder owns the typed Work Artifact author, inspect, validate, fresh-render review, repair, and deliver lifecycle. The Analyst independently validates source facts, citations, calculations, and unknowns. File existence, parsing, or self-authored validation JSON is never canonical acceptance.

The current package is deliberately limited to the qualified `office.presentation@1` profile. DOCX, XLSX, PDF, existing-presentation editing, and coordinated multi-format packs remain unsupported until each has its own qualified profile and release evidence.

The package-local method is clean-room OpenCorvus work; no third-party Office Skill was copied without package-wide license evidence.

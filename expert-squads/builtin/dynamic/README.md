# Dynamic

Dynamic is a lightweight direct-dispatch Expert Squad. Its Orchestrator derives the smallest useful ephemeral team and dependency description from the current Task, writes that description in the same visible streamed message, and immediately starts every ready member through the existing `dispatch_agent` runtime.

The package declares two reusable capability envelopes, not two permanent team roles. `dynamic-generalist` serves generated planning, investigation, analysis, review, verification, and synthesis members. `dynamic-builder` serves generated implementation and concrete-delivery members. Either identity may back multiple independent sibling Sessions; the generated member name and responsibility remain dispatch-time instructions, while the projected identity remains the exact runtime authority.

Dynamic declares no binding virtual workflow, package writer, hidden task list, workflow engine, or runtime-created manifest identity. Use Generate Expert Squads when the requested deliverable is a persistent, installable package; use a governed domain Squad when its fixed roles, evidence contracts, and repeatable topology matter more than runtime flexibility.

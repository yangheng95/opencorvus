# Dynamic Selection

Select Dynamic when the current Task benefits from a small team whose member responsibilities and dependency shape should be chosen immediately from the request instead of loaded from a fixed domain workflow.

Dynamic is appropriate for mixed investigation, planning, implementation, review, and synthesis where the exact partitions are request-specific. Prefer one member for one bounded job; add members only for independent work that can proceed without shared mutable ownership. Select a fixed specialist Squad when its domain controls, typed Artifact handoffs, or repeatable workflow are required.

Dynamic does not author or install a new Expert Squad. Select Generate Expert Squads only when the deliverable is a persistent project-owned package. A Dynamic Task keeps the exact `builtin/dynamic` package revision and executes a visible direct-dispatch plan through real worker Sessions.

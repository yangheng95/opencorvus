# Construction Project Controls

Scope, schedule, cost, procurement, site-risk, and quality evidence joined into an accountable project controls register.

Run the WBS/schedule, cost/procurement, and interface/site-risk/quality branches independently, then dispatch the join owner only after all three versioned reports exist. Every scheduler and worker uses `construction-project-controls/shared/method`. The Skill saves WBS/schedule, earned-value/change, interface/procurement/site-risk, and integrated controls assets with data dates, formulas, units, source versions, owners, uncertainty, and applicable work domains.

Never certify design or construction, direct site activity, interpret contracts, approve change orders, procurement, invoices, or payments, or issue safety or permit clearance. Require authorized project, engineering, quantity-surveying, safety, legal, and commercial review.

The method is a bounded adaptation of baseline discipline, dependency mapping, variance reporting, risk ownership, and executive decision records from `alirezarezvani/claude-skills` at pinned commit `aa8d778811a557a2c28ccadda4cf3d0bd028a4cc` under MIT. It excludes software-portfolio assumptions, upstream scripts and fixed financial models, global agent protocols, and engineering, contractual, site, procurement, change, or payment authority.

# Maritime Port Operations

Maritime Port Operations prepares a bounded, source-grounded port review through three independent professional views: vessel call/berth/nautical services, terminal yard/gate flow, and cargo document/safety/custody. `maritime-port-operations-review-owner` is the explicit join and cannot run until all three branch reports exist.

Every port, terminal, berth, anchorage, vessel call, voyage, cargo unit, container, document, equipment resource and custody event keeps stable identifiers, units and time zone, source location, version and effective date, owner, qualified reviewer, applicability, uncertainty, and status. Draft, length, berth, tidal, productivity, capacity, Verified Gross Mass, dangerous-goods, customs and security criteria come only from current named authorities.

The package never navigates a vessel, directs Vessel Traffic Services, orders pilots or tugs, clears a berth, dispatches equipment or labor, handles cargo, classifies or stows dangerous goods, grants customs/security release, contacts external parties, or directs pollution/emergency response. Those decisions remain with harbour masters, VTS operators, pilots, masters, terminal control, dangerous-goods specialists, customs/security authorities, port-state bodies, and emergency responders.

Use `maritime-port-operations/shared/method` only after all three independent port branch reports exist.

## Input contract

Require exact paths, versions and hashes for the port baseline, vessel-call/berth plan, terminal-flow ledger and cargo-document/custody register; common port-call, voyage, berth, cargo-unit and event keys; units/time zone and evidence cutoff; source authorities and effective dates; accountable port owner; qualified reviewers; authorization boundary; unresolved unknowns; and excluded decisions. Reject incomplete or incompatible branches.

## Domain method

Confirm each root remained independent and source-addressable. Reconcile only stable call, berth, cargo-unit, document and time keys. Create contradiction rows when vessel milestones, terminal windows and documentation/custody states disagree. Preserve requested, predicted, confirmed and actual states. Use only port-supplied priority and risk criteria; do not invent berth priority, productivity, safety or clearance scores. Link each bounded evidence action to source need, dependency, owner, reviewer, due/review date, applicability, uncertainty, status, decision authority and stop condition.

## Evidence output

Complete `port-operations-integrated-review-pack.md` with branch artifact/version/hash, joined findings, conflicts, missing authorities, dependency chain, bounded evidence-review actions, owners, qualified reviewers, applicability, uncertainty, status, decision-not-made, stop/escalation and a separate human-decision register. Return no vessel, terminal, cargo or public-authority instruction.

## Unknown and stop conditions

Stop when a branch is absent, vessel/call/cargo identity conflicts, time zones or versions differ materially, live navigation/terminal state appears, approved criteria are missing, security/privacy boundaries would be breached, or a conclusion would imply berth clearance, equipment readiness, VGM acceptance, dangerous-goods classification, customs/security release or legal compliance.

## Authority and qualified review

Never direct VTS, vessel, pilot, tug, mooring, berth, crane, yard, gate, rail, barge, cargo, customs, security, dangerous-goods, pollution or emergency activity. Route decisions to harbour master, VTS/pilot/master, terminal control, equipment/labor owners, documentation and dangerous-goods specialists, customs/security, port-state/regulatory bodies and emergency authorities. Record their later decision without making it.

# Site Readiness and Activation Evidence Matrix

Map each readiness requirement to the protocol/site/jurisdiction and an approved plan or current authoritative source selected by a qualified owner. `Present`, `current`, `approved`, `effective`, `applicable`, and `ready for owner decision` are distinct. No row authorizes site activation or enrollment.

## Matrix basis

- Matrix ID / version / status:
- Study / protocol / amendment / effective date:
- Sponsor / site / country-jurisdiction / study stage:
- Approved startup plan, essential-document index, and source versions/dates:
- Systems of record/export versions and evidence cutoff/time zone:
- Applicable capacity or timing units:
- Participant-data/privacy classification:
- Responsible clinical-operations owner / Principal Investigator / qualified regulatory, ethics, quality, pharmacy, laboratory, privacy, and site reviewers:
- Excluded actions, known conflicts, and overall uncertainty:

# Meteorological Observation Forecast Assurance

This package prepares station/sensor metadata, observation quality-control, forecast cycle and valid-time provenance, observation–forecast alignment, and verification evidence. Three independent roots converge into one explicit assurance review owner.

It does not issue or alter forecasts, nowcasts, watches, warnings, advisories, routes, flight/marine/agricultural instructions, emergency decisions, sensor settings, or official products. The bounded OpenClaw MIT adaptation retains only provenance, structured-data, untrusted-content, source-separation, and official-service escalation concepts.

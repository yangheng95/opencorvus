# Medical Imaging Quality Assurance

This package prepares traceable imaging equipment, protocol, phantom technical quality-control, DICOM workflow, display-chain, dose-index, and nonconformance evidence for qualified review. Four independent workers feed one explicit join owner.

It never operates imaging systems, changes protocols, renders or de-identifies DICOM, judges clinical image adequacy, estimates patient dose, returns equipment to service, or declares compliance. Use the five package assets as the only structured handoff and retain every source, version, unit, uncertainty, decision withheld, and escalation.

The package boundedly adapts the pinned K-Dense pydicom Skill under MIT. See `skills/method/references/UPSTREAM.md`, `ADAPTATION.md`, and `LICENSE.md`.

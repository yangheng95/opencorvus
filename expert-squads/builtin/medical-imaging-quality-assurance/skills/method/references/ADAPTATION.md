# Bounded adaptation

## Retained

- Work only from authorized local evidence and preserve source/version provenance.
- Minimize Protected Health Information before analysis.
- Preserve DICOM metadata, transfer syntax, frame, and derived/source context when evidence is supplied.
- Treat de-identification as an expert-reviewed workflow, not a casual field deletion.

## Modified

The retained concepts are rewritten into a read-only quality-assurance evidence method covering device/configuration baselines, phantom measurements, transfer/display reconciliation, dose-index context, and nonconformance/CAPA traceability. All outputs use package assets and route consequential interpretation to named qualified humans.

## Excluded

No upstream installation advice, Python examples, scripts, networking, package-version or vulnerability defaults, DICOM reading/writing/rendering/transcoding/de-identification, file mutation, diagnosis, clinical image acceptance, patient-dose decision, system operation, accreditation, or compliance conclusion is retained. No upstream example dataset or generated output is included.

# Knowledge Base Operations selection

Select this Expert Squad when source material must become a traceable knowledge-base addition, update, deprecation, or replacement with an explicit publication record. Preserve the source set, source versions and dates, target knowledge space, destination path or stable key, audience, owner, review policy, existing canonical entries, and publication authority.

Use the exact `grounded-knowledge-release` workflow. Source mapping, update editing, and lifecycle governance run independently. The publication integrator joins their exact Artifacts and records the final landing, change, lifecycle, and release evidence.

Use direct document editing for one-off prose that is not entering a governed knowledge lifecycle.

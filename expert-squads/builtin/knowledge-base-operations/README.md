# Knowledge Base Operations

Knowledge Base Operations prepares a source-grounded knowledge release through three independent specialist views: source and destination mapping, update editing, and lifecycle governance. `knowledge-publication-integrator` is the explicit join node.

Every knowledge claim must land on a traceable source record and a named destination key. Updates preserve the previous canonical entry, material differences, affected links, ownership, review dates, and replacement relationships. Deprecation never silently deletes history.

The package publishes a prepared knowledge record and publication evidence inside the Task Artifact chain. It does not mutate an external knowledge base, announce a release, or mark content approved without an authorized publishing capability and approval evidence.

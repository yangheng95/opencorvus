# Identity Access Governance

Identity lifecycle, account-entitlement, access-control and certification evidence joined for qualified governance review.

Run the four zero-dependency professional branches concurrently. Dispatch `identity-access-governance-review-owner` only after all four reports exist. The scheduler and every worker project the single package Skill `identity-access-governance/shared/method`.

This package prepares source-addressable evidence for qualified review. It does not execute external or production actions, make regulated or professional determinations, or convert missing evidence into assumed facts. See `selector.md` for scope and stop conditions.

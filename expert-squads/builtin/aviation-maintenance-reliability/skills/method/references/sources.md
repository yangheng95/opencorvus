# Clean-room source record

## Primary public methods

- FAA Advisory Circular 120-17B, Reliability Program Methods—Standards for Determining Time Limitations: https://www.faa.gov/regulations_policies/advisory_circulars/index.cfm/go/document.information/documentID/1035253
- FAA Advisory Circular 120-16G, Air Carrier Maintenance Programs: https://www.faa.gov/regulations_policies/advisory_circulars/index.cfm/go/document.information/documentID/1028859
- Electronic Code of Federal Regulations, 14 CFR Part 43, Maintenance, Preventive Maintenance, Rebuilding, and Alteration: https://www.ecfr.gov/current/title-14/chapter-I/subchapter-C/part-43

These sources informed only the clean-room structure for evidence, reliability-program records, maintenance-program traceability, authorization boundaries, and qualified review. Operators must supply the current controlling version and approved manufacturer/operator data. This package does not reproduce regulatory or advisory-circular prose.

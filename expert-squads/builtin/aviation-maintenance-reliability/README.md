# Aviation Maintenance Reliability

Aircraft configuration, maintenance reliability, and planning evidence converge into a review pack for authorized continuing-airworthiness and maintenance personnel.

Run the configuration-and-records, maintenance-reliability, and planning-and-airworthiness branches concurrently. Dispatch the join owner only after all three source-addressable reports are complete. The scheduler and every worker use the single package Skill aviation-maintenance-reliability/shared/method.

The method is clean-room authored from public FAA reliability-program, air-carrier-maintenance-program, and maintenance-record frameworks. Two repository Skills were evaluated and rejected: the MIT mechanical RCM Skill is too general to carry aviation records or release authority, and a direct aviation maintenance Skill has no verifiable license. No rejected text is copied.

Never issue troubleshooting or maintenance instructions, change a task interval or approved program, interpret an Airworthiness Directive, Service Bulletin, Minimum Equipment List, or Configuration Deviation List, defer work, certify a part, sign a record, or approve return to service. All material findings require current operator/manufacturer-approved data and review by appropriately authorized aviation personnel.

# Meeting Knowledge Operations

Meeting Knowledge Operations converts exact meeting material into reviewable minutes, a decision log, an action register, open questions, and reusable knowledge. Source curation and outcome classification run independently, then a single editor joins both results and a separate reviewer checks traceability and publication boundaries.

The package does not record meetings, infer consent, manufacture consensus, assign an owner who did not accept an action, or publish confidential material to an external system. The operator remains responsible for recording consent, access policy, approvals, and external publication.

The method Skill was authored clean-room for OpenCorvus and does not reproduce third-party Skill text.

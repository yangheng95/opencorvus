# Viral Content

Viral Content produces evidence-backed, text-led campaign copy. Viral means a falsifiable distribution hypothesis, never a promise of reach, engagement, or revenue.

## Optional collaboration guidance

evidence-backed-content-campaign is optional collaboration guidance. Audience and trend research run in parallel after the campaign brief, then concept selection, copy production, independent review, and Build-owned delivery run in order.

## Artifact contract

Every worker publishes its package-owned type through the single typed publisher. Consumers discover, completely read, and select exact predecessor Artifacts themselves. Only viral-delivery-owner writes files. It writes and rereads artifacts/viral-content/campaign.md and artifacts/viral-content/campaign.json, verifies, commits, and merges them when working in a managed worktree, reads and snapshots the exact immutable returned primary_head, publishes viral-content/delivery, and presents matching document and table Interactive Artifacts.

This package creates text-led content. It does not claim that a visual prompt is a finished image or that a content hypothesis guarantees virality.

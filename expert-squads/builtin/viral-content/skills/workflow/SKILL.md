# Viral Content workflow

Use only evidence-backed-content-campaign. Every node runs once after all declared predecessors reach terminal success. Audience and trend research are the only parallel frontier. Artifact bodies never travel through dispatch prose. Every worker uses the package typed publisher. Only the delivery owner writes, rereads, verifies, and commits final files; when merge_back is available it requires a merged result, completely reads the final files from the exact immutable returned primary_head, passes that same value as artifact_snapshot.source_commit, and publishes the files and matching presentation from those commit bytes without any post-merge write or Git mutation. A primary-project run without merge_back omits source_commit and snapshots the reread files directly.

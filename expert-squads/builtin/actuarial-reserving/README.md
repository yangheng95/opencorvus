# Actuarial Reserving

An evidence-first property and casualty unpaid-claim reserving squad. Four independent roots reconcile source data and triangles, examine methods and assumptions, test uncertainty and validation evidence, and trace governance, roll-forward and disclosure. A fifth owner joins those branches into one qualified-review pack without selecting a final estimate, booking a reserve or issuing an actuarial opinion.

The package uses one local Skill, `actuarial-reserving/shared/method`, and five controlled assets. It is clean-room authored from public professional-source concepts identified in `skills/method/references/source-provenance.md`; no rejected repository text, protected standard text, formula implementation or example data was copied.

Select it for bounded reserving evidence where valuation date, accounting basis, portfolio scope and source records are supplied. Do not use it to replace an appointed actuary, determine a booked reserve, sign an opinion, set pricing or capital, interpret law/accounting/tax, or decide an individual claim.

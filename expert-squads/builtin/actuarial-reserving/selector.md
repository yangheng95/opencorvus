# Selector

Select this squad when the requested output is a reproducible evidence pack for unpaid-claim data reconciliation, incremental and cumulative triangles, development and tail assumptions, chain ladder or Bornhuetter-Ferguson-style supplied calculations, reserve uncertainty, actual-versus-expected diagnostics, roll-forward or disclosure traceability.

Require an explicit entity, line/coverage, accident or report period, development grain, valuation date, currency, gross/net and ceded basis, paid/incurred/case basis, expense treatment, discount basis, data cutoff, source versions, responsible owner and qualified actuarial reviewer. If those boundaries are absent, return a gap register rather than infer them.

Do not select this package for pricing, life/health liabilities, pension valuation, capital modeling, investments, claim adjudication, legal/accounting/tax conclusions, a reserve recommendation, booked-reserve authorization, regulatory filing, actuarial opinion or certification. Those decisions remain with the appointed actuary and other named authorities.

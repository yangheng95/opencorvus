# Selection guidance

Select for ISO 26262-oriented evidence preparation concerning item definition, operational situations, HARA trace, safety goals, functional and technical concepts, system/hardware/software requirements, failure/dependent-failure analyses, verification, validation, configuration, changes, anomalies, distributed-development interfaces and confirmation measures.

Require vehicle/item/variant, intended functions and boundaries, operating context, lifecycle phase, standard edition authorized for use, OEM/supplier responsibility split, configuration baseline, evidence cutoff, decision and qualified safety reviewers. Stop rather than invent ASIL, failure rates, diagnostic coverage, acceptance criteria or completeness.

Do not select for fleet operations, ordinary manufacturing nonconformance, vehicle cybersecurity, homologation, live vehicle action or production release.

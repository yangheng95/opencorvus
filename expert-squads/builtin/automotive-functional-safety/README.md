# Automotive Functional Safety

This squad prepares a source-bound functional-safety evidence pack for a named road-vehicle electrical/electronic item, vehicle variant, operating context and lifecycle baseline. Independent roots cover item definition and supplied HARA evidence; safety concept and requirement traceability; hardware/software safety analysis and verification; and lifecycle/configuration/change/confirmation evidence. The join creates a safety-case gap register without approving the product.

Manufacturing Quality retains defect and production-control disposition; Cybersecurity Assurance retains malicious-threat and security-control analysis; fleet safety retains driver and operating-fleet programs. This package addresses hazards caused by malfunctioning behavior of the bounded E/E item. It cannot assign ASIL, approve safety goals or architectures, qualify tools/components, judge validation sufficient, authorize release or control a vehicle.

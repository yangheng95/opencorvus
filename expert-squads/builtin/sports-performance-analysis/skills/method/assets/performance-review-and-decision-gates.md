# Performance Review and Decision Gates

Join exposure/load, testing/reliability, and availability/wellbeing evidence only when athlete scope, authorized purpose, time window, units, definitions, devices, protocols, and privacy boundaries are compatible. The result is a review hypothesis, not a medical, coaching, selection, employment, or athlete-management decision.

- Review ID / version / status:

- Analysis horizon/time zone and evidence cutoff:
- Exposure/load ledger, test/results, reliability/change, and wellbeing-log versions:
- Device/algorithm/protocol/instrument versions and units:
- Applicable population, competition/training context, and privacy/safeguarding class:
- Responsible performance owner / coach / sport scientist / medical / privacy / athlete reviewers:
- Missingness, incompatible evidence, excluded actions, and overall uncertainty:

# Measurement Reliability and Change Register

Use this register to distinguish observed change from measurement error and a locally approved meaningful-change criterion. A statistical value is usable only when the protocol, sample, calculation, assumptions, units, software/version, and qualified interpretation owner are explicit.

## Reliability basis

- Register ID / version / status:
- Test/metric ID, protocol/version, device/algorithm/version, units, and applicable athlete population:
- Reliability sample IDs/count and sampling domain:
- Repeated-measure interval and relevant environment/athlete context:
- Calculation method/software/version/date and evidence cutoff:
- Responsible owner / statistician or measurement specialist / sport-science reviewer:
- Local meaningful-change policy/rubric ID/version/owner, if any:
- Missingness, exclusions, assumptions, limitations, and overall uncertainty:

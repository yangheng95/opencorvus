# Selection guidance

Select this Squad for source-grounded service and dependency identity, service-level indicator/objective and error-budget evidence, telemetry and alert quality, incident timeline and impact evidence, role and handoff context, post-incident contributing factors, learning and owned follow-up actions.

Provide the service/catalog identity, owners and dependencies, SLI/SLO definitions and versions, measurement windows and exclusions, telemetry/query/alert configuration versions, incident and change identifiers, source cutoffs, time-zone/clock basis, privacy and access constraints, existing command structure, action system of record and named reliability, service, incident-command, observability, security and change reviewers.

Do not select it for cloud architecture design, cybersecurity attribution, data-pipeline implementation or emergency continuity planning. Never use it to declare severity, page responders, run mitigation, change production, send status communications, infer root cause without evidence, assign blame, or approve incident/action closure.

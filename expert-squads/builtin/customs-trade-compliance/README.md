# Customs Trade Compliance

An evidence-first customs/trade squad. Four zero-dependency specialists freeze transaction/documents, develop classification evidence, trace origin/valuation/preference and examine screening/licence/entry controls. The explicit owner joins evidence without making a regulated determination, filing or shipment decision.

The package projects only `customs-trade-compliance/shared/method`, owns exactly five assets, and records a fixed MIT upstream source with retained/excluded adaptation boundaries.

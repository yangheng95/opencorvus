# Selector

Select this squad for an integrated industrial or service robot application where the requested product is a traceable requirements, task-hazard, safeguard, safety-function and verification/validation evidence case.

Require the exact robot application, hardware/software/safety configuration, end effector and payload, external equipment, environment, tasks, modes, lifecycle phases, exposed persons, jurisdiction, risk criteria, evidence versions, owner and qualified reviewer. When these are absent, return a bounded gap register.

Do not select it for automotive vehicle functional safety, generic AI model governance, manufacturing defect control, live robot programming or commissioning. It cannot accept residual risk, determine legal compliance or substitute for the integrator, employer/user or qualified robot-safety authority.

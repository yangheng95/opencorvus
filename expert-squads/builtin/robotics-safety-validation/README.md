# Robotics Safety Validation

An evidence-first integrated-robot safety squad. Four zero-dependency specialists freeze the application boundary, analyze task/mode/lifecycle hazards, trace safety functions and organize layered deterministic test evidence. An explicit case owner joins their outputs without accepting risk or commissioning equipment.

The package projects one local Skill, `robotics-safety-validation/shared/method`, to the scheduler and every worker and owns exactly five reusable evidence assets. The Skill is a bounded Apache-2.0 adaptation of Robotics Agent Skills testing concepts plus clean-room safety methodology. Exact source, license, retained concepts, exclusions and modifications are recorded in `skills/method/references/source-provenance.md`.

Select it for review of supplied robotics requirements, hazards, safeguards and validation evidence. Do not use it for live control, ROS execution, safety-configuration changes, safeguard bypass, PL/Category/SIL calculation, risk acceptance, compliance declarations or release decisions.

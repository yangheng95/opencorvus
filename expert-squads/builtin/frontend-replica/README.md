# Frontend Replica

Frontend Replica delivers source-bound desktop interface parity from an existing URL, screenshot, or source-context snapshot. One Planner binds source identity, target project, surface inventory, interaction obligations, owned paths, and rendered acceptance. Explorer, intent analysis, interface modeling, source research, workload analysis, and implementation then execute as parallel workers that consume only that plan.

The Implementer owns the complete target UI, module comparison, scroll-slice and changed-region proof, real Browser interaction, diagnostics, fresh screenshots, and repair. Source evidence must remain traceable to exact immutable locators; blank geometry filler and unrendered placeholders are not parity. The Orchestrator accepts only Host-observed implementation plus current rendered evidence.

This package does not project platform Visual Reviewer or Integrity Reviewer identities. Visual acceptance remains mandatory and UI automation remains prohibited.

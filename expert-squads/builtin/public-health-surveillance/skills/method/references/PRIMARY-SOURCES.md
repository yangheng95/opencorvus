# Primary clean-room method sources

No official text, case definition, threshold, law, deadline, or current public-health conclusion is copied. Use operator-authorized current versions and record applicability.

- CDC, Updated Guidelines for Evaluating Public Health Surveillance Systems: https://www.cdc.gov/mmwr/preview/mmwrhtml/rr5013a1.htm
- CDC, Framework for Evaluating Public Health Surveillance Systems for Early Detection of Outbreaks: https://www.cdc.gov/mmwr/preview/mmwrhtmL/rr5305a1.htm
- CDC, A Standard Framework for Evaluating Large Health Care Data and Related Resources: https://www.cdc.gov/mmwr/volumes/73/su/su7303a1.htm
- WHO, Defining collaborative surveillance: https://www.who.int/publications/b/69325

These sources inform high-level system, data-quality, denominator, lag, and multi-source concepts only. Jurisdictional classification, reporting, investigation, disclosure, and action remain with current official sources and qualified authorities.

# Deep Research workflow

Use only `multi-perspective-report`. Run every node once and only after its declared predecessor reaches terminal success. Evidence is the typed Artifact chain, never copied dispatch prose or visible assistant summaries.

Every worker searches the current Task catalog by output type and immutable workflow/node provenance, completely reads inspected candidates, selects exact supporting Artifacts, and publishes one complete structured output. The final writer resolves the citation review, writes canonical Markdown, rereads and snapshots it, then publishes both `deep-research/report` and the matching `document@1` view.

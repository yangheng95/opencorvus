# Selection guidance

Select for a named facility fire-protection review involving adopted-basis identity, occupancy and hazards, passive compartmentation and egress evidence, detection/alarm/suppression/water-supply interfaces, supplied fire-model provenance, inspection/testing, defects, or impairments. Do not select for chemical-process hazard analysis, wildfire resource management, incident command, emergency response, live system operation, design approval, code interpretation, evacuation orders, or compliance certification.

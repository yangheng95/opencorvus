# Selection guidance

Select this package for source-grounded failed physical-component identity and custody, as-received condition, service/design/manufacturing history, fracture origin and morphology, metallography/composition/hardness/mechanical-test evidence, loads, environment, fracture-mechanics applicability and competing hypotheses.

Do not select it for software incidents, generic manufacturing disposition, laboratory accreditation, vehicle HARA/ASIL, aircraft or well release, semiconductor-device failure analysis, destructive evidence handling, root-cause/liability conclusions, fitness-for-service, rework/recall/scrap or return-to-service decisions. Require current method/standard metadata, specimen orientation/location, calibrated measurements, uncertainty and qualified professional review; morphology alone never proves cause.

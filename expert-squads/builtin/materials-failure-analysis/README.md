# Materials Failure Analysis

This package prepares traceable physical-component failure evidence for qualified review. Independent roots freeze identity, as-received condition, custody and history; map supplied fractography and material characterization; and reconcile loads, environment and bounded mechanics before a review owner joins competing hypotheses.

It is distinct from manufacturing-quality disposition, laboratory quality-system assurance, automotive functional safety, aircraft maintenance release, petroleum well integrity and semiconductor yield. It analyzes supplied physical materials evidence across industries while explicitly excluding semiconductor device-level failure analysis and application-specific fitness decisions.

Every scheduler and worker uses only `materials-failure-analysis/shared/method`. Five assets preserve evidence identity/custody, specimen location/orientation, source/method/version/date, measurements/units, instrument/calibration, service loads/environment, hypotheses and counterevidence, assumptions, uncertainty, owner, qualified reviewer, status, decision-not-made and stop/escalation.

No output touches, cleans, cuts, etches, dismantles or tests evidence; declares root cause, defect, liability or culpability; performs fitness-for-service; or decides rework, recall, scrap or return to service. Those decisions remain with qualified materials/metallurgical, fractography, mechanical/fracture, corrosion, NDE, laboratory, product/application, evidence/legal and regulatory authorities.

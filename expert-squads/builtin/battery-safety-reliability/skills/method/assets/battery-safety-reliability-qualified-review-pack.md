# Battery Safety Reliability Qualified-review Pack

## Package identity and authority

Record `artifact_id`, package version/hash, evidence cutoff, product/application/configuration IDs, source locator/version/date inventory, quantity/unit/denominator and time basis, owner, battery/electrochemical, BMS/electrical, thermal/mechanical/fire, reliability/statistics, laboratory/test-safety, quality, hazardous-goods, application and certification reviewers, applicability/jurisdiction, assumptions, uncertainty, status, `decision_not_made` and `stop_or_escalation`.

This is a join of frozen evidence, not an operating/test instruction, safety case, certificate, release or emergency/transport decision.

## Required branch closure

1. Configuration/envelope register hash, genealogy/BMS/protection/application compatibility and unresolved changes.
2. Abuse-test ledger hash, authorization, SOC/SOH/preconditioning, instruments/calibration/clocks/raw-data and event-definition limitations.
3. Propagation/barrier map hash, chronology, configuration, conflicting observations and generalization limits.
4. Failure/reliability register hash, population/exposure/outcome/censoring/model assumptions and uncertainty.

## Joined evidence

List each claim with source asset/row and classification as source fact, observation, derived calculation, hypothesis, assumption, uncertainty or unknown. Build a contradiction table for configuration, lot, SOC/SOH, event clocks/terms, measurements, tests, populations and criteria. Never choose a convenient record or infer acceptance from non-propagation in one test.

## Qualified-review and stop matrix

Record open source/data needs, accountable owner and qualified reviewer without synthesizing approval. Stop/escalate for active heat/venting/fire/damage, configuration mismatch, missing authorization/calibration/raw data, unsupported event definition or reliability model, stale application source, or any live test/operation/BMS/handling/emergency/transport/product/certification request.

`decision_not_made` enumerates: no operating envelope, BMS/protection setting, test procedure or pass/fail, thermal-runaway cause, propagation/barrier effectiveness, reliability/service life, damaged-battery handling, emergency/transport, certification, release or safety decision was made. Human decisions stay in authorized systems.

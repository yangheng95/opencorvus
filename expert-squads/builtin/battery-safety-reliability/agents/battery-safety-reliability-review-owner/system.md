Use `battery-safety-reliability/shared/method` only after the three independent battery branches complete.

## Input contract

Require exact versions/hashes of the configuration/envelope register, abuse-test ledger, propagation/barrier map and failure-reliability register; shared configuration/sample/lot/test/event/time/unit/application keys; current controlled criterion sources; evidence cutoff; every mismatch, censored record, instrumentation limitation and model uncertainty; accountable owner; battery, electrical/BMS, thermal/mechanical/fire, reliability/statistics, test safety, quality, transport, application and certification reviewers; and excluded decisions.

## Domain method

Join only compatible configuration and application evidence. Reconcile test sample genealogy and SOC/SOH against the baseline; reconcile instruments, clocks and event terminology; reconcile propagation/barrier observations without assuming causality; reconcile failure populations, exposure, censoring and model assumptions. Keep source criterion, observed response, derived calculation, hypothesis, uncertainty and application acceptance distinct. Preserve contradictory sensors, tests, lots and field data.

## Evidence output

Complete `battery-safety-reliability-qualified-review-pack.md`. Include branch hashes, joined configuration keys, source and criteria table, event chronology, propagation/barrier evidence, reliability population/model table, contradiction/uncertainty register, reviewer matrix, open evidence requests, decision-not-made and stop/escalation. Every claim must cite a frozen asset row and source/version/date.

## Unknown and stop conditions

Stop for configuration mismatch, unknown SOC/SOH or preconditioning, non-comparable test/application, missing calibration or clocks, undefined thermal-event term, incomplete population/censoring/exposure, unsupported reliability model, stale application criterion, active damaged/hot battery or fire, hazardous operational request, or output implying test, BMS, handling, emergency, transport, certification, release or safety decision.

## Authority and qualified review

Never issue operating/test/handling/emergency instructions, change BMS/protection, declare thermal-runaway cause or barrier effectiveness, set reliability/service-life limits, certify, release or claim a system safe. The pack is evidence for qualified decision owners. Leave all pass/fail, design acceptance, transport, product, operational and certification fields unfilled.

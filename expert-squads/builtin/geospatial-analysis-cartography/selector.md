Select this Squad when authorized spatial data needs CRS/datum/geometry audit, raster-vector analysis planning, operation reconciliation, spatial uncertainty review, or purpose-led accessible cartographic specification.

Provide area of interest, intended decision and audience, output medium and scale range, source datasets with versions/licenses/dates, feature IDs, CRS identifier/WKT, datum/epoch/axis/unit, raster resolution/grid/nodata/resampling semantics, accuracy/precision metadata, sensitive-location and privacy rules, approved output destination, and named reviewers.

Do not select it to guess an unknown CRS, acquire remote data, mutate a database or live map style, repair authoritative geometry, disclose restricted locations, establish cadastral/legal boundaries, replace a licensed survey, provide emergency navigation, autonomously choose a route/site, or publish. Missing CRS, source license, lineage, sensitivity, or authority is a stop condition.

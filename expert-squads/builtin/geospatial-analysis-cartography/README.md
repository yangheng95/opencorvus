# Geospatial Analysis and Cartography

Spatial source and coordinate-reference integrity, raster/vector analysis provenance, and accessible cartographic design converge into a controlled publication-review pack.

Run the spatial-data/CRS-integrity, raster/vector-analysis, and cartographic-design/accessibility branches concurrently. Dispatch the join owner only after all three source-addressable reports exist. Every scheduler and worker uses geospatial-analysis-cartography/shared/method.

The method is a bounded MIT adaptation of GeoPandas and GeoMaster Skills from K-Dense-AI/scientific-agent-skills at pinned commit d661d27ef4ddad5b9287bdd84887ace27e2320b8 and MapLibre Cartography from maplibre/maplibre-agent-skills at efacb28bae72f0b01f838179776af8b71c99a065. Exact source paths, full licenses, retained concepts, and exclusions are saved locally. External installs, cloud/API/data acquisition, database or style writes, automatic CRS guesses, runtime mutation, vendor services, secrets, and universalized example styling are excluded.

Never expose sensitive locations, claim cadastral/legal/survey accuracy, support emergency navigation, make autonomous route/site decisions, destructively repair source geometry, or publish without authorization. Require data-owner, GIS, survey, privacy/security, accessibility, legal and publication review as applicable.

# Hazard Analysis Control Point Evidence Plan

## One-row grain

Create one row per ingredient or process-step hazard hypothesis and supplied control relationship. Capture `hazard_row_id`, artifact version, facility/product/process-flow/step versions, hazard category, source/cause/condition, source locator/version/date, effective date/cutoff, supplied severity and likelihood scale sources/values, quantity, unit/denominator, prerequisite/control reference, monitoring/verification/validation links, owner, qualified reviewer, applicability, assumptions, uncertainty, status, decision_not_made, and stop reason.

## Template row

- hazard_row_id / artifact_version: `FSQ-HAZ-____ / ____`
- product_formulation / process_flow_step / ingredient_supplier_specification: `____ / ____ / ____`
- hazard_category: `biological | chemical | physical | allergen`
- hazard_source_cause_condition and evidence locator: `____ / ____`
- source_version / source_date / effective_date / data_cutoff: `____ / ____ / ____ / ____`
- supplied severity scale/source/value: `____ / ____ / ____`; leave blank if not authorized
- supplied likelihood scale/source/value: `____ / ____ / ____`; leave blank if not authorized
- quantity / unit / denominator: `____ / ____ / per lot, batch, serving, sample, or declared population`
- prerequisite program or already-authorized control reference: `____`
- monitoring / verification / validation evidence links: `____ / ____ / ____`
- owner / qualified_reviewer: `____ / HACCP team or PCQI plus microbiology, toxicology, allergen, process, laboratory roles as applicable`
- applicability / assumptions / uncertainty: `____ / ____ / ____`
- privacy_license_boundary: `authorized sources; no protected standard text`
- status: `hypothesis | evidence-collected | qualified-review-required | conflicting | stopped | superseded`
- decision_not_made: `no hazard-significance, preventive-control, CCP, critical-limit, adequacy, safety, or compliance decision`
- stop_reason: `missing source, scale, product/step applicability, authority, unit, or qualified specialist`

Do not add a generic severity/likelihood matrix. The qualified food-safety team performs significance and control decisions in its controlled system.

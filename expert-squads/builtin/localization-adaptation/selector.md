# Localization & Adaptation selection

Select this Expert Squad when source content must be adapted for one or more named language-locale pairs and the result needs controlled terminology, locale conventions, and linguistic quality evidence. Preserve source version, audience, target locale, channel, tone, glossary, do-not-translate terms, variables, markup, legal constraints, and release format.

Use the exact `locale-release-pack` workflow. Terminology, locale adaptation, and linguistic quality assurance run independently from the same source scope. The release integrator joins their exact Artifacts and resolves conflicts into the final locale pack.

Do not select it for free-form rewriting without a locale target or for publishing directly to an external channel.

# Nonprofit Grant Operations

Funder fit, program evidence, budget, compliance, and delivery readiness joined into a traceable grant operations pack.

Run the three evidence branches independently, then dispatch the join owner only after all branch reports exist. Every scheduler and worker uses `nonprofit-grant-operations/shared/method`. The package includes a requirement traceability matrix, a logic-model and indicator register, a budget/post-award control register, and the joined grant delivery plan.

Never fabricate need, outcomes, partners, beneficiary facts, match funding, or commitments; never determine legal or tax compliance, sign, certify, submit, accept an award, or approve spending. Require authorized program, finance, legal, safeguarding, executive, and funder-facing review.

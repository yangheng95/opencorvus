# Air Traffic Management Safety

Airspace configuration, demand/capacity, hazard/control and assurance evidence joined for qualified ATM safety review.

Run the four zero-dependency professional branches concurrently. Dispatch `air-traffic-management-safety-review-owner` only after all four reports exist. The scheduler and every worker project the single package Skill `air-traffic-management-safety/shared/method`.

This package prepares source-addressable evidence for qualified review. It does not execute external or production actions, make regulated or professional determinations, or convert missing evidence into assumed facts. See `selector.md` for scope and stop conditions.

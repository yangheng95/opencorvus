# Frontend Innovate

Frontend Innovate turns an existing product or source URL into a new, source-informed desktop interface. One Planner first binds the resource boundary, user tasks, direction-selection contract, owned paths, and acceptance evidence. Explorer, intent, design, source research, deep research, workload analysis, implementation, and fact checking then form one dependency-ready worker frontier.

Workers consume only the Planner Artifact; they do not wait for one another or manufacture a Requirements → Architect → Implementer chain. The Implementer owns real-page interaction, fresh screenshots, diagnostics, and repair of the delivered UI. The Fact Checker independently validates claims and cited resources. The Orchestrator accepts only Host-observed implementation, current rendered proof, and complete worker evidence.

This package does not project platform Visual Reviewer or Integrity Reviewer identities. Removing those roles does not relax visual acceptance: UI automation remains prohibited, and real rendered desktop evidence remains mandatory for delivered UI work.

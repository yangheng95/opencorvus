# Frontend Innovate Selection

Select this Expert Squad for an existing URL or product that must be redesigned toward a new aesthetic, professional, or more convenient desktop experience while retaining evidence-backed source and user-task context. Select Frontend Replica instead when literal source parity is the objective.

Bind `frontend-innovation-delivery`. Dispatch `frontend-innovate-planner` first. Its plan must name the resource boundary, source/reference inputs, user-task model, candidate-direction evidence, selected-direction decision contract, non-overlapping worker ownership, target files, and real-page acceptance. Then dispatch the declared workers when capacity permits; every worker depends only on the plan.

The Experience Designer owns HTML/CSS design-draft evidence and selected-direction rationale. The Implementer owns product changes, accessibility behavior, state/data integration, real-page interaction, fresh desktop screenshots, and repair. The Fact Checker owns independent claim/source validation. No worker may wait for a future worker Artifact or recreate the removed Requirements, Architect, Visual Reviewer, or Integrity Reviewer roles.

The Orchestrator judges completion from immutable worker Artifacts, Host-observed files and command exits, the implemented page, fresh screenshots, interaction and diagnostic evidence, and explicit unresolved blockers. It does not accept prose-only design or screenshots disconnected from the delivered implementation.

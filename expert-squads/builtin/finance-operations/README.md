# Finance Operations

Finance Operations reconciles supplied operational finance records and reviews the controls around them. Record analysis and control analysis run independently before a single join owner prepares a close or remediation plan. A separate reviewer checks the joined plan for source lineage, unresolved exceptions, and explicit human approvals.

This package is operational decision support. It does not provide financial, investment, accounting, audit, legal, or tax advice. It never files a return, posts a journal entry, releases a payment, moves funds, approves a close, certifies controls, or replaces a qualified accountant, controller, auditor, tax professional, or accountable executive.

The method Skill was authored clean-room for OpenCorvus and does not reproduce third-party Skill text.

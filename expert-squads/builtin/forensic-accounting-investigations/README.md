# Forensic Accounting Investigations

An authorized-evidence forensic accounting squad. Four zero-dependency specialists control investigation scope and custody, reconcile transaction populations and anomaly leads, reconstruct funds flow and entity links, and test controls/interviews against corroboration and contradiction. An explicit evidence owner joins the work without accusing anyone or making a legal decision.

The package projects one local Skill, `forensic-accounting-investigations/shared/method`, to the scheduler and every worker and owns exactly five reusable assets. It is a bounded MIT adaptation of FinanceSkills forensic-accounting concepts. Exact source, license, retained concepts, exclusions and modifications are recorded in `skills/method/references/source-provenance.md`.

Use only under explicit authority with identified evidence and qualified counsel/CFE/CPA review. It cannot access accounts, determine fraud or illegality, label suspects, infer intent, file a SAR, freeze assets, refer law enforcement or issue an audit opinion.

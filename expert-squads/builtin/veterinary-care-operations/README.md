# Veterinary Care Operations

This package assembles source-bound veterinary intake and care-pathway, diagnostic/order/medication/procedure, anesthesia/recovery, inventory/cold-chain/biosecurity, and controlled client-follow-up evidence. Four independent roots converge into a qualified-review owner.

It does not diagnose, triage live emergencies, recommend tests or treatment, calculate doses, prescribe, administer, operate systems, decide discharge/referral/euthanasia/isolation/reporting, release inventory, or contact clients. The pinned MIT client-discharge source is adapted only for controlled clinical-record versus client-summary separation.

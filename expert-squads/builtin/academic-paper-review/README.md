# Academic Paper Review

Review an authorized manuscript through an explicit evidence chain rather than one undifferentiated critique. The package separates literature coverage, novelty, logic, methods and statistical validity, factual consistency, citation and hallucination risk, and presentation quality before an integration editor produces the review register.

## Binding workflow

`academic-paper-review` is the only workflow. Charter planning, reproducible literature mapping, and presentation inspection are three independent roots. Logic, methods/facts, and citation/hallucination review start from the frozen charter; novelty review depends on the completed literature landscape. The integration editor joins novelty and every integrity branch without erasing disagreements.

## Skill and assets

Every projected role receives `academic-paper-review/shared/academic-paper-review-method`. The package saves seven dedicated assets: the integrated review register, reproducible literature-search protocol, novelty/prior-art matrix, argument map, methods/fact recalculation register, claim-citation-hallucination ledger, and presentation-quality checklist. The Skill is a bounded adaptation of four individually MIT-licensed K-Dense scientific review Skills at a pinned commit, with provenance and license stored in the package.

## Authority boundary

This Squad drafts evidence-traceable review work for an authorized human reviewer. It does not decide publication, impersonate a venue or editor, provide specialist ethics/statistics approval, upload confidential manuscripts to third parties, or treat bounded literature search as proof that a contribution or citation does not exist.

## V9 local H3 production

The production host has one RTX 5090 (32 GB VRAM) and 64 GB system RAM. The full BF16 H3 components do not fit, so this pipeline uses the community-qualified ComfyUI path: a pruned INT8 ConvRot FL2VA diffusion model, NVFP4 AWQ Qwen3-VL text encoder, the two H3 VAEs, and ComfyUI DynamicVRAM. The four model files total about 39.6 GiB and retain native video plus stereo-audio generation. The installation manifest labels these as third-party quantized/repackaged weights rather than implying an official full-precision run.

Install into the isolated demo directory:

```powershell
.\script\video\minimax-h3-mission-promo\install-local-h3.ps1
```

Generate the H3-native world bootstrap. This starts only the isolated local ComfyUI service on port 8188, computes physical SHA-256 for every selected model, submits the three-field prompt, records GPU/RAM/temperature samples, and extracts five review frames:

```powershell
$python = 'C:\Users\hengu\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $python .\script\video\minimax-h3-mission-promo\generate-local-h3.py `
  --shot R00 --take take-001 --width 608 --height 352 --steps 10 --seed 20260825
```

After human review, add the accepted R00 frame paths and SHA-256 values to the manifest reference assets. Every production take is immutable and addressed by shot, take label and build digest:

```powershell
& $python .\script\video\minimax-h3-mission-promo\generate-local-h3.py `
  --shot S01 --take take-001 --width 608 --height 352 --steps 10 --seed 20260825
```

Mode is selected only from the manifest. T2VA accepts no references, I2VA accepts one, FL2VA binds both first and last frame to the local node, and Ref2VA requires two references plus the physical Ref2VA INT8 weight. Missing assets, wrong SHA, absent weights, old storyboard input and duplicate take destinations all fail closed.

Composition first restores every native `608×352` H3 clip into an immutable external cache with per-clip input/output/model/tool SHA receipts, then scales the restored clips into the 1080p delivery master. This is documented post-restoration, not a claim of native H3 1080p generation.

Install and verify that portable restoration runtime before composition:

`voice`, `animatic`, and `compose` currently fail by design because the only storyboard is rejected. The retained animatic is evidence of the rejected direction, not a production candidate.

First approve `preproduction-v3.zh-CN.md` (project brief and story outline). Then create and separately lock labeled character cards and environment-only scene cards. After approval, the production sequence is:


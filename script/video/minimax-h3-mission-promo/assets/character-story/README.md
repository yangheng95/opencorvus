# Character story assets

These images are the frozen identity source for the character-led promo direction.

- `character-bible-v1.png`: the only approved base identity for the protagonist and Agent cast.
- `user-pain-keyframe-v1.png`: the first story keyframe derived from that bible; it is the input to H3 image-to-video, not a standalone slide.

Character contract:

- The protagonist always keeps the same dark rounded curls, navy round glasses, mint overshirt, white T-shirt, charcoal trousers, and coral sneakers.
- Every Agent uses the same warm-white rounded robot body, black face screen, and cyan oval eyes. Teal, blue, amber, and violet accents identify research, implementation, test, and independent review.
- The story contains no live-action person, photoreal human, bird, raven, feather, or Corvus mascot. The official OpenCorvus logo is reserved for deterministic opener/outro branding.
- Generated frames contain no readable copy. Product names, URLs, metrics, and subtitles are added deterministically in post-production.

The source prompts and acceptance decisions are recorded in
`specs/records/2026-08/2026-08-24-minimax-h3-mission-promo-video.md`.

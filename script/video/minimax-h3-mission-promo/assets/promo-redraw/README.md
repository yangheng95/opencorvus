# Mission promotional figure redraws

These two 1920×1080 figures are promotional redraws of the canonical Task 3
paper figures. They do not replace the paper evidence.

- `architecture-promo-v1.png`: selected DeBERTa V3 base ABSA architecture.
- `lifecycle-promo-v1.png`: evidence-governed training-to-delivery lifecycle.
- `brand-opener-v1.png`: centered brand opener with the official raven logo.
- `brand-outro-v1.png`: information-led closing card with all public addresses.
- `*-plate-v1.png` and `lifecycle-plate-v2.png`: text-free computational image plates generated with the
  built-in image generation tool.
- `*-promo-v1.svg`: deterministic typography, metrics, and flow overlays.

Run `node script/video/minimax-h3-mission-promo/render-promotional-figures.mjs`
from the repository root to rebuild the PNG outputs.

## Image-generation prompts

The architecture plate requested a premium 16:9 semiconductor-scale AI
visualization with paired inputs, a central DeBERTa compute core, three
sentiment outputs, and one restrained gold training-feedback loop. It excluded
text, metrics, UI, code, HUDs, node-network bubbles, cyberpunk scenery, and
watermarks.

The lifecycle plate requested a premium 16:9 left-to-right AI delivery line
covering CUDA training, validation selection, frozen selection, read-only test,
and best-asset product consumption. It required a visible dimmed comparison
path and excluded text, metrics, UI, code, HUDs, toys, and watermarks. The v2
plate replaces the ambiguous multi-GPU rack with exactly one GPU module while
preserving the remaining topology.

All factual labels and numbers are rendered from the SVG overlays rather than
generated by the image model.

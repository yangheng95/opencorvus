# AutomationBench 证据边界

本目录不是 AutomationBench 复现结果。`audit.json` 逐字段记录科学复现闭包，`run-ledger.json` 保存本任务真实运行的网页常量正向检查及原始输出。

允许引用：当前网站源显示用户更正的 100-case strict-pass 对照（8.07% → 34.00%），并且 25.93 percentage-point 与 4.21x 算术一致。

禁止引用：命名版本上的可复现 34%、显著优于基线、投稿级效果或跨不同样本的排名。取得 benchmark version、case-level 数据/协议/评价器、逐 case 输出、非秘密环境配置、日志、重复运行和统计后，才可新建科学复现记录；不得回填或推测缺失值。

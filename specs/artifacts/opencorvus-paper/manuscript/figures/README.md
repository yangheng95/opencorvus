# Color scientific figures

The three current figures are original raster assets generated using the built-in image-generation tool, documented as GPT Image 2. The user explicitly authorized Image 2 on 2026-09-10 after the exact Image 2.5 selection limitation was explained. No API key, separately billed API path, or paid fallback was used. The tool exposes no model selector or verified backend snapshot.

- [Organization anatomy](architecture.png), [LaTeX wrapper](architecture.tex): five Research Studio experts, their reusable procedures/resources, and the three actual workflow declarations.
- [Specialization and worked revision](specialization.png), [LaTeX wrapper](specialization.tex): domain resources, shared analytical contract, existing distributed obligations, candidate rewrite, transfer hypothesis and possible costs.
- [Evolution and independent evaluation](evolution.png), [LaTeX wrapper](evolution.tex): development cycle, paired trial slots, final selection, independent future/retention tasks, and complete resource accounting.
- [Exact prompts, asset hashes and generation decisions](prompts.json).

All assets are RGB PNG files at 1536 × 1024. At the manuscript text width they provide approximately 279 pixels per inch. Labels are rasterized, not editable LaTeX text. The wrappers carry captions and cross-reference labels; there is no second TikZ drawing implementation. Regeneration must be followed by exact label, connection and PDF-size visual inspection.

## Visual references and originality

The author searched and actually viewed [AFlow Figure 3, PDF page 5](https://proceedings.iclr.cc/paper_files/paper/2025/file/5492ecbce4439401798dcd2c90be94cd-Paper-Conference.pdf) and [GEPA v2 Figure 3, PDF page 5](https://arxiv.org/pdf/2507.19457v2). AFlow makes its search space and operator internals visible; GEPA exposes candidate relationships, feedback and selection. These informed the choice to show internal method objects and explicit evaluation boundaries. Neither third-party figure was copied, supplied as a generation input, or redistributed in the final assets. Original PDFs and rendered reference pages remain ignored local reading material.

## Meaning and review

Colors encode categorical responsibilities and method regions. Revision labels, trial cells and connecting lines depict method structure, not measured data. Figure 2 is a worked hypothesis, not an empirical case or a verbatim source diff. Its artifact contract is analytical notation. Figure 3 does not imply that selection guarantees improvement.

All labels and directed connections were manually checked before integration. Independent review established that the parent already contains claim mappings and report-model validation. Figure 2 was regenerated to depict an explicit local reorganization of these obligations, with larger step text. Initial incorrect digest typography, a spurious double-headed dependency arrow, role-to-field misalignment, poor-background variants and an ambiguous export route were rejected and regenerated. Local-path image editing failed with the Windows sandbox helper ACL error for both generated-image and workspace paths; complete corrected prompts were used for new generations. No pixel-editing substitute or credential fallback was used. Final PDF and independent review status is recorded in [validation](../validation.md).

The older recovery/evidence filenames and all superseded TikZ drawings were replaced, not kept as parallel current implementations.

A fresh independent review found that the prior figures required enlargement to read several labels. All three current assets were regenerated with larger type and reduced duplicate annotations while preserving the substantive mechanism. Final PDF-width review, rather than readability of the original enlarged PNG alone, determines acceptance. The selected prompts and hashes identify this replacement round.

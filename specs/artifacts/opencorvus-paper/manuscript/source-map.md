## Important implementation distinction

The candidate-author prompt and README describe a narrower update policy than the production integrity comparator. Its mutable descriptive manifest fields are top-level name/label/description, selector summary/selection_guidance, and agent/workflow/node labels/descriptions. All other declaration fields except version stay fixed under that policy. Both were inspected at the same frozen version. The manuscript preserves this distinction: the representation admits structural editing; the present generator is prompted for procedural text; the text study arm additionally checks realized changes. A prompt is not a hard support-set restriction on an LLM.

The comparator's capability check is over the union of references already declared anywhere in the parent. It is not a per-role authority-preservation guarantee. Path/graph validity is not proof of semantic workflow correctness. Frozen executable bytes do not freeze remote services.

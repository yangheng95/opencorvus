# 连接设置键盘提交证据

- `baseline-enter-no-feedback.png` 是本人在真实桌面地址字段内输入 `#review` 后按回车的结果。
- `baseline-click-validation.png` 是同一草稿随后点击 Save 的产品片段错误。
- `candidate-enter-validation.png` 和 `candidate-malformed-validation.png` 是新版从地址框回车显示的两种实际错误。焦点保持在地址框。
- `candidate-enter-save.png` 是有效地址从地址框提交的 Saving 状态。
- `candidate-username-saved.png`、`candidate-password-saved.png` 和 `candidate-click-saved.png` 分别为用户名、空密码字段回车和鼠标点击的 Saved 状态。
- `candidate-reloaded-address.png` 是重新打开设置后仍带尾斜杠的已保存地址。
- `candidate-proxy-enter.png` 是代理地址输入后回车，代理字段仍有焦点且连接草稿保持的结果。
- `candidate-keyboard-button.png` 是 Tab 到连接 Save 并以回车提交后，按钮保持焦点、代理草稿仍在原区的结果。

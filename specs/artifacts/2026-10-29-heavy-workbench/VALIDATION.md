# 验证账本

仅记录真实发生的验证，工具测试不能推导受测系统能力。

| 对象 | 当前状态 | 证据边界 |
| --- | --- | --- |
| 10题/200叶、权重和输入可读性 | 已执行definition_valid | `python script/benchmark/heavy_workbench.py validate` |
| 输入及40张客观参考表 | 已从固定原创数据生成 | 参考计算不是完整专家交付 |
| 聚焦正向契约测试 | 34/34通过 | [原始输出](validation/unit-tests.txt)，含十领域已知小输入、计分、固定输入完整性及明确错误合同 |
| 10题真实checker运行 | 40/40诊断叶通过 | [回执](validation/checker-replay.json)，原始输入导出后重算并进入CLI；不是模型端到端 |
| H06/H08/H10计划验算 | 七组基础/压力可行见证 | 同一回执；验证物料/依赖资源/能量等真实数据约束，非最优性认证 |
| H05旧故障真实复现 | 重启翻倍且原跨租户漏计可见 | 同一回执；独立agent复查得到同一金额，只验证题目输入真实可复现 |
| H08基础可行证据 | 38日、67400 CNY | 同一回执；依赖下界26日，工程师工作量下界38日 |
| 独立agent逐题审查 | 四轮后认可设计/离线工具，范围内无剩余阻断 | [逐项记录](REVIEW.md)，明确不认可经验成熟度、不替代领域专业人员 |
| 完整专家参考交付 | 未达成 | 需要每领域专业人员完成真实成品 |
| 真实受测系统全题运行 | 未达成 | 本次没有授权使用私有凭据，也没有调用额外Provider |
| 人类评分校准与区分度 | 未达成 | 需要独立专家真实多质量产物与一致性统计 |
| 系统隔离与正式适配 | 未达成 | prepare不是安全边界，未注册生产task/solver |

当前不能宣称benchmark已具备成熟项目的实证效度、模型在本题通过、职业专家水平或公开排名效度。

`bun run docs:check` 已实跑通过：351 ops / 26 groups。所有诊断、参考可行见证与测试输入由同一任务作者制作，不能作为独立评分器校准集。评分合成测试中的满分是明确标注的合成机制样例，不是职业参考成品。

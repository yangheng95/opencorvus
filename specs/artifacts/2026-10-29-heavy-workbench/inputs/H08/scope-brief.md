# 虚构数据平台与培训项目范围

目标：在隔离环境交付可复跑的数据平台、学习实验和教师/运维交接包。禁止外部生产部署、真实学员招募或采购。本表是业务范围权威，records.csv是工期、角色和依赖权威；资料标题不隐含额外先后关系，需新增依赖应在建议中作为变更说明。当前承诺38工作日、90000 CNY。

| Task | 工作 | 交付 | 验收结果 |
|---|---|---|---|
| T00 | 范围与源资料清单 | 源系统边界、数据字典及负责部门清单 | 每项资料有身份、更新人和目标用途 |
| T01 | 目标存储原型 | 隔离SQLite存储原型与字段定义 | 样例订单能写入并按身份查询 |
| T02 | 独立画像工具 | 可在输入CSV运行的数据质量画像器 | 输出缺失率、唯一键与字段范围 |
| T03 | 培训需求调查 | 24名学员能力访谈和差距摘要 | 每角色能力目标与调查依据可定位 |
| T04 | 批量导入器 | 根据源资料实现完整输入导入 | 记录数、货币与源身份逐项核对 |
| T05 | 业务验收目录 | 依据存储合同列出业务核对用例 | 每个核心字段有明确输出合同 |
| T06 | 质量规则实现 | 使用画像与导入数据实现质量检查 | 规则返回可定位行与明确错误码 |
| T07 | 课程与实验范围 | 依据需求明确课程和实验边界 | 每学习目标映射到一个实验 |
| T08 | 字段血缘实现 | 导入字段到目标字段的血缘索引 | 任一目标字段能回查源字段及变换 |
| T09 | 教学实验数据接口 | 根据业务验收和课程范围提供隔离实验接口 | 实验端可取到规范数据并核对字段 |
| T10 | 数据忠实性复核 | 基于质量规则对完整输入出具核对底稿 | 主要金额、身份及完整性有逐项事实 |
| T11 | 完整课程材料 | 按课程范围编写教学示例与答案 | 替代讲师可完成一节课试讲 |
| T12 | 集成平台候选包 | 结合血缘和数据复核构建可运行交付候选 | 从输入可完整生成下游实验数据 |
| T13 | 实验成本与容量审查 | 审查实验接口资源、存储与预算使用 | 容量估计与实际计量范围一致 |
| T14 | 权限与审计实现 | 根据数据忠实性结果实现访问控制审计 | 两种授权角色得到各自明确数据范围 |
| T15 | 课程试教 | 使用教学材料和获批实验容量完成隔离试教 | 记录实际答题、失败与修改建议 |
| T16 | 运行观测实现 | 为集成包接入指标及错误定位 | 一个故障能从真实观测定位到输入 |
| T17 | 恢复能力实现 | 依据容量成本审查完成备份与恢复 | 从备份恢复后数据和业务查询一致 |
| T18 | 操作验收复核 | 结合访问控制与运行观测出具操作核对 | 授权、异常定位与数据核对可独立执行 |
| T19 | 教师使用指南 | 根据试教记录编写独立教师手册 | 新讲师能定位示例、答案与故障处理 |
| T20 | 运维步骤文档 | 根据运行观测交付日常操作步骤 | 照步骤能获取状态并处理已知异常 |
| T21 | 评审签收材料 | 汇总恢复能力和教师指南用于内部评审 | 签收材料指出证据、剩余风险及责任 |
| T22 | 离线交付封装 | 根据操作验收结果制作可重建离线包 | 新目录按命令可构建并查询数据 |
| T23 | 最终培训与移交 | 依据教师指南完成最终课程移交 | 交接人获得资料、演示与后续更新入口 |

变更边界：压力情景T07增加3日，其他范围/容量不变。基础及压力计划必须各自核对依赖、资源、成本和完工承诺；有余量时可保持同一业务承诺，但需展示真实重算。项目计划任务不要求实际实施上述全部平台功能，要求制定足以指导团队完成它们的范围、排程、成本、验收与移交方案。

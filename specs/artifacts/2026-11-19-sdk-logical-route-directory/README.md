- `baseline-runtime.json`：真实服务/代理请求，两个前缀的项目身份、缺目录错误和直接服务诊断会话；基线诊断网页不代表错误前缀成功。
- `baseline-project-text.png`：本人在真实桌面展开 B 项目诊断原件。
- `candidate-runtime.json`、`candidate-checks.json`：真实前缀请求、准确项目身份、两个项目事件流、持久回复及原件/实际下载字节核对。
- `candidate-project-text.png`：本人展开由带前缀 SDK 创建的候选会话和原件，人工核对所属项目与正文。
- `candidate-attempt-error.json`、`proxy-errors.json`：最初临时代理拒绝逐跳头的真实失败原因和请求；不作为产品通过证据。
- `focused-checks.json`：实际 19 项 SDK 和 4 项上传测试输出。
- `runtime-audit.json`：只读数据库和真实流式参与者请求/完成事实，正常退出后的输入所有权收敛。

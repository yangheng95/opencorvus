工作线程能把同步启动成本移离主线程，但命令总耗时没有稳定优势。内部 Git 的局部优势不证明可以自动替代 PATH 包装器：它承载环境语义且内部布局非稳定入口。本轮不保留生产 worker、内部二进制探测、并发策略或配置变化。探针中的每线程模块还各自产生运行 occurrence，虽然物理 PID/出生时间相同；直接把整个 Process 模块移到 worker 也不能当作已符合生产单一运行身份的设计。

人工二次复核实际384个结果、全部16个组的live0、原close/清理和worker exit0；数据输出只保留所选自有项目的两条实际Git路径与原进程身份，没有环境或凭据正文。四个自有runtime/data目录为空，未创建数据库或授权文件。没有操作用户18571或用户窗口，未运行UI自动化。后续应先依据完整保存的关键路径评估成熟异步启动边界，不重复本轮线程数量、内部路径或已排除的detached/stdio/log实验。

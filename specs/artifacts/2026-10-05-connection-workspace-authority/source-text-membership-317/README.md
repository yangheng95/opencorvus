## 事实与修复

实际Task HTTP（Hypertext Transfer Protocol，超文本传输协议）会返回空字符串text Part，只有reasoning从呈现载荷省略。新的检查先通过生产Session写入空正文和来源，再经真实Bus发布未落盘的完整文字字段；后续接口仍返回空正文Part，投影应显示接受的完整文字。如果该Part实际已删除，后续接口只返回存活来源，此前观察的文字字段也应退出。

316把text缺席也当作可能的空正文，错误保留了已撤回文字。现在只有省略的reasoning、未提交pending工具和无法分类的纯字段观察保持原例外；已知text在本次读取中缺席时，旧snapshot及其字段一起退休。仍在读取中的Part继续接受未落盘字段，不按总游标、长度或时钟猜测它已持久化。未知类型的纯字段没有基底Part时不能自行构造正文。

没有更改HTTP协议、数据库结构、模型调用或Host调度。316资源观察/同一完成值的显示和清理顺序保持。已同步更正当前07架构，以及316方案/结果中的过宽说明；原日志作为当时执行事实保留。

## 修复

SubagentConversationPanel现在在请求前捕获已收到的live对象引用。原createResource一次交付本次接收范围、合并后的transcript和请求前观察；显示memo在这同一次完成值上应用reconcile，随后effect清理现有动画帧队列/信号。这样不会先清掉live、再等待下一微任务切换HTTP（Hypertext Transfer Protocol，超文本传输协议）base而短暂露出旧内容。

313的终态内容规则和314/315已知成员排除仍处理各自的事实；本轮解决“首次读取没有旧base”和“旧实时删除标记压住后续恢复”的顺序缺口。普通Side的有序连接快照仍重置live，没有平行重写其连接流程。

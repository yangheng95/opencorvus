- Search and get relevant external programming context using Exa Code API
- Tool name: `external_code_search`
- Use this tool for third-party libraries, SDKs, APIs, frameworks, and code that is NOT in the current repository
- Do NOT use this tool to inspect, search, or verify files, symbols, or behavior that exist in the local repository or workspace
- Returns comprehensive external code examples, documentation, and API references
- Optimized for finding programming patterns and solutions outside the current codebase

Usage notes:
- First search the local repository with `search_code`/read tools when the question is about this project, its files, or its behavior
- Use this tool only when local code search cannot answer the question because the needed context is external
  - Adjustable result count with numResults (default 8)
  - Returns publisher titles, source URLs, and available code highlights or documentation text
  - Supports queries about third-party frameworks, libraries, APIs, and programming concepts
  - Examples: 'React useState hook examples', 'Python pandas dataframe filtering', 'Express.js middleware'

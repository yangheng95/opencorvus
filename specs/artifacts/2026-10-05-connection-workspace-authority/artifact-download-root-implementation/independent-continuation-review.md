## One source-visible gap: current accessor exceptions are treated as retirement

ArtifactActions matchesCurrent catches every props.files() error and returns false. Every owns/showsCopied/effect call therefore treats failure to generate the current authoritative material as source mismatch. Concrete current producer: artifactExports spreadsheet branch throws "CSV export exceeds 2,000,000 cells" for its actual used range; SpreadsheetArtifact's current runtime export accessor also may throw load/export failure. After an operation has started with valid material, a current accessor that throws during a subsequent ownership check causes silent retirement: operation effect aborts/releases it, or action's owns returns false, or run catch calls owns and returns. The accessor's original exception is lost. This conflicts with the explicit amendment that current deliberate export failures remain observable. It is not evidence of an actual observed incident; reproduction is unknown.

Trigger sequence: successful current files snapshot → operation awaits clipboard/blob/copyAccessor → same mounted API/selection/accessor now throws on current files generation → matchesCurrent catches → false → original continuation/error is suppressed and no current export error is reported. This differs from a successfully generated changed material, which legitimately retires original action. No API classifier/finally/cached blob issue is required. Current clipboard accepted truth must remain intact even if this generation error follows its native reply.

Bounded recommendation for Root: distinguish exact lifecycle/API/accessor/material mismatch from current material-evaluation failure in existing guard, preserving the actual thrown cause. Surface a current export-generation failure once through existing diagnostics while releasing only original operation; do not turn it into a fake transport error or re-run export to manufacture a different result. Source-safe checks must precede material evaluation, so disposed/retired API operations do not publish an old accessor's error. Avoid adding a registry/cache/new abstraction. Pure service tests cannot qualify this component ownership path; Root manual page with a legitimate failing export producer is the applicable acceptance, without component/render/UI automation.

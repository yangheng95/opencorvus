### Lifecycle/path cases

- Create→modify: explicit producer add/existence state establishes absent→present. Empty string alone cannot distinguish absent file from existing empty file. Compose only with contiguous completed after/before and same scope/lineage; final status is added and endpoints absent-baseline→final content.
- Modify→delete: actual delete metadata plus contiguous preimage proves present→absent; final net deleted with earliest content. Create→delete returns an explicit no-net-change absence→absence result with two observed operations, not a fabricated deleted/added row.
- Move A→B: preserve source A and target B from canonical metadata; compose subsequent B edits only when that actual lineage is unambiguous. Source recreation A is a separate lineage. Current target-path-only merge cannot prove this relationship or separate it from independent creation B.
- Revert0→1→0: with actual causal sequence, net result has identical endpoint text and zero net additions/deletions, while two operation sources remain. Identical content cannot be used to discard a distinct operation or collapse a parallel ambiguity.
- Parallel same-agent: agent identity/Part creation order does not serialize filesystem writes. Overlapping events must remain explicit components until producer/causal facts qualify one chain. Across agents/projects/sessions, no aggregation merely because names/paths/content match; absolute path itself is insufficient when different authority/project contexts claim separate subjects.
- Replay/update: current same Part identity is one latest canonical observation; two events for it are not two edits. Distinct immutable tool receipts with equal bodies remain distinct operations. Snapshot path-list Parts are excluded from body composition because current canonical shape has no full before/after; no new invented Tool/Patch association is proposed.

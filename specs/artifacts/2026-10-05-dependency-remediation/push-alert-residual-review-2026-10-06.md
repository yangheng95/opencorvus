### 1. GLib: narrow official backport, not forced type migration

Current installed glib `src/variant_iter.rs` still declares immutable pointer `p` and passes `&p` in VariantStrIter::impl_get. The [upstream merged PR1343](https://github.com/gtk-rs/gtk-rs-core/pull/1343) corrects exactly pointer mutability; [official0.20 implementation](https://raw.githubusercontent.com/gtk-rs/gtk-rs-core/0.20/glib/src/variant_iter.rs) has mutable p and passes &mut p. Public [0.18 branch](https://raw.githubusercontent.com/gtk-rs/gtk-rs-core/0.18/glib/src/variant_iter.rs) checked here still shows the defect; the PR's backported label is not proof of a released0.18 fix.

Local candidate: use a single attributed Cargo patch source for glib0.18.5 carrying only this official pointer correction, preserving public type signatures/features/sys dependencies. The product currently has no Cargo vendoring/patch entry; implementation must first select one reproducible Cargo [patch.crates-io] source with upstream license/provenance and reviewed minimal delta, not mutate ~/.cargo cache, silently fork a crate or leave alternate current sources. Cargo's source replacement retains the existing0.18 graph and directly repairs the undefined behavior. A version-only GitHub/RustSec scanner can still flag0.18.5 afterward; do not claim patched advisory-range identity or suppress the finding to manufacture scanner success.

Why parent version forcing is not minimal: installed webkit2gtk2.0.2 explicitly requires glib/gio/gdk/etc ^0.18.0; installed Wry0.55.1 on Linux/BSD targets selects GTK0.18 and exact WebKitGTK2.0.2, while current [official Wry dev0.57 manifest](https://raw.githubusercontent.com/tauri-apps/wry/dev/Cargo.toml) still selects these same GTK/WebKit versions. tauri-runtime-wry2.11.1 requires Wry0.55.0. glib0.20 is a distinct semver/type family shared with gio/gdk/gtk/pango/sys traits and wrapper types; replacing only glib cannot satisfy those constraints. Updating Wry blindly neither establishes a GTK migration nor eliminates this issue. A full GTK4/WebKit6 architecture migration has product window/IPC/rendering implications and is outside a minimal security fix.

Acceptance after authorization: actual optimized glib iterator next/next_back/nth/nth_back/last UTF-8 output using the selected patched library, with exact borrowed string lifetimes and remaining len; optimized consumer build on an owned Linux environment with real GLib headers/libraries, plus actual Tauri Linux startup/webview/window/IPC behavior and screenshots where UI changes arise.

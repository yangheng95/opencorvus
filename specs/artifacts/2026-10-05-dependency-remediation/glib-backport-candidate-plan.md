## Complete public iterator and FFI surface

`Variant::array_iter_str(&self)` (variant.rs843) checks the actual Variant type against String::static_variant_type().as_array(), returns the existing VariantTypeMismatchError for a mismatch, then returns VariantStrIter borrowing that Variant. New is crate-private. The iterator contains `&'a Variant`, head and tail, and returns `&'a str`; no owned String, alternate cache, or copied Variant is needed.

| Surface | Actual operation and qualification |
| --- | --- |
| Iterator::next | impl_get(head), then increment head; exercise actual first/next strings. |
| Iterator::nth | bounds/overflow check, skip n then impl_get(end); exercise a middle value with exact residual length. |
| Iterator::last | consuming iterator, impl_get(tail−1) if nonempty; exercise fresh and partially consumed sequences. |
| DoubleEndedIterator::next_back | decrement tail then impl_get(tail); exercise actual final string. |
| DoubleEndedIterator::nth_back | reverse bounds/overflow then impl_get(end−1); exercise a skipped reverse value. |
| size_hint / count / ExactSizeIterator::len | tail−head only; they do **not** call impl_get, so passing them alone cannot validate the defect. |
| FusedIterator and inherited collect/rev/map/fold/for_each | standard trait composition reaches the overridden front/back methods; collection order plus mixed traversal must be real outputs, not source assertions. |
| Separate VariantIter | owns a Variant and returns child_value Variants; not the defective borrowing iterator. Keep unchanged. |

glib-sys0.18.1 declares g_variant_get_child(value:*mut GVariant,index:size_t,format:*const c_char,...). Format `&s` writes a pointer to borrowed serialized UTF-8 bytes; it does not allocate a string for the caller to free. [GNOME get_child](https://docs.gtk.org/glib/method.Variant.get_child.html) and [GVariant format strings](https://docs.gtk.org/glib/gvariant-format-strings.html) define this borrowed conversion. The owner Variant must remain alive and serialized storage stable for returned &'a str. The proposed mutation affects the **pointer slot**, not character bytes or ownership; p still has the same C-sized pointer type, same `&s` format/index/trailing vararg and same CStr validation. Do not substitute a null check, cloned string, different format or fallback getter to conceal the undefined write.

Search of the installed public Cargo registry for array_iter_str found GLib implementation/docs/tests rather than a demonstrated Wry/GTK production caller. Repository Rust sources do not directly call this method. This narrows known direct exposure, but generic/transitive C/Rust composition and future calls remain unqualified; absence of a literal call is not an exploitability or Linux-safe claim. The five FFI-reading methods must all be tested even if a current GUI journey does not invoke them.

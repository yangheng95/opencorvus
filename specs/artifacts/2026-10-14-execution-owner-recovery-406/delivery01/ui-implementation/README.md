Root should decompress and compare original bytes when executing the eventual capture, without turning mutable-source hashes into a functionality gate.

The helper-preparation failure `ui-helper-prepare-failed01.json`, original helper preimages and resulting helper patch remain available for Root's manual-helper selection; they are not implementation/check failures and have not been silently relabeled or deleted.

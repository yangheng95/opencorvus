# 本机执行合同（冻结前载体修订）

用户明确要求本机运行。当前受控执行使用原生 Windows 进程、独立 Python 环境与同一张 CUDA 设备，记录实际 argv、工作目录、进程标识、开始/终态、依赖版本和完整源；不依赖容器。不声明同用户的文件系统、内存、网络或侧信道隔离认证。

原已完成的 Linux 首格及其原件保留。后段只执行原注册未完成格，保留首格权重、计数与声明；环境差异须在论文中说明，不能称为相同操作系统的冷启动对照。原八数组网络、初始化复用、数据、19个基础配置、5个续训、方法、选优与科学目标均不改变。

评估侧执行收据为 `l01-controlled-execution/2`：`execution_id/backend/pid/pid_scope/project_root/argv/started_at/finished_at/state`。自然结束后 `state` 为 `{"status":"exited","exit_code":实际整数}`。历史闭合容器收据仅由显式元数据迁移器投影为 `historical-container`，原始日志和大型状态原件继续保留；不能写成新 Windows 执行。

`--continue-study` 只用于自然完成前段后的原未执行格；它不替代任意中断后的优化器恢复。实际保存状态的分叉恢复仍用 `--resume`，保留原优化器和随机状态。长训练由定时唤醒核对，不持续监听，也不重复已完成配置。

# L02 局部资格工具

`current-source/asof_input.py`是唯一发布时间投影；`check_projection.py`共享格式校验、独立SQL重建许可集合，并绑定评估侧指定origin/horizon；`forecast_reference.py`只消费快照，用Fraction精确OLS。`qualify_l02.py`执行解析样本的真实隔离进程、CLI错误合同与手算对照。完整原始vintages只在评估侧，不能挂给预测进程。

当前仅合成整数tick的信息边界资格。完整研究质量、预测区间、多序列、嵌套选模、业务交付、完整rubric及数小时候选证据尚未建设。新执行原件与独立审查按[资格记录](../../../../../records/2026-10/2026-10-30-heavy-workbench-l02-qualification.md)归档；原始失败保留，不用样本数量冒充难度。

[主方原执行](qualification/main/result.json)是两个真实微型worker与解析对照；[独立最终审查](qualification/independent-review/REVIEW.md)及[机器结论](qualification/independent-review/stage-assessment.json)记录三个假通过/修复与唯一新cold。两边originals.zip保留原字节、实际命令/退出/挂载和所有首失败；主方初checker执行不冒称修后执行。当前局部blocking=[]不代表全题批准，不重复秒级实验凑工作量。

# April month-end package: quality and evidence

The original task and original input files are supplied locally. Prepare the consolidated April workbook for CFO review, preserving the March template's structure, formatting and tab order. Keep Tab0's contents current; exclude the CFO-reserved 1/2/2a/3 sections; update 3a onward and append genuinely new April schedules. The original requested filename is `Aurisic_Financials_4-25-1.xlsx`.

Do all work supported by the available records. An unresolved source discrepancy does not authorize invented transactions, unexplained balancing adjustments, treating missing values as zero or retaining an old-month value under an April label. Identify the affected balance, both source locations, amount/direction of any computable difference, what is known and what is needed from the CFO. A CFO notification belongs in the workbook or a draft accompanying the handoff; do not send external messages.

The supplied file list omits `AP_TB-1.xlsx`, although the original request names it. Its absence is public. The April general-ledger AP balance and the unavailable detailed AP support must remain distinct. Similarly, a bank-book control does not establish an independent bank-statement balance, and one source copy's displayed total does not establish formula correctness.

These dimensions have no aggregate100, hindsight quality cutoff or guaranteed ranking. Correct uncertainty disclosure is not a substitute for completing the calculations that the inputs do support. A prefilled supporting schedule is not automatically correct; check the result and disclose any adopted correction.

This is a local research task preparation, not an official GDPval score, unseen-task guarantee, professional certification or effective-hour qualification. No minimum duration, unnecessary plot, repeated experiment or prescribed library is required. A complete package can still be unready for model evaluation if its sources, consumer or quality judgments have not been validated.

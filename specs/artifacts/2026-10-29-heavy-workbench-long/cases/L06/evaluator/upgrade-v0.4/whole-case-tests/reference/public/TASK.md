# Active inspection, procurement and original-receipt recovery

Build a usable eight-week operating policy and a native standard-input/output actor for this synthetic factory. Purchasing and choosing which retained lot to inspect change the future observable information. Each week has a laboratory decision followed by an operations decision after the actual laboratory result. Deliver all three complete supplied instances; an invariant CSV-row reorder is the only additional declared input control.

Use the original tables and [operational law](OPERATIONS.md), not a selected hidden class or future result. The class is fixed through an episode; conditional on it, different tested lots are independent. No actor receives the class or future outcomes. Only an actual paid inspection is a new sample. Quantify what can and cannot be identified, including labels with equal laws under every admissible adaptive experiment. Do not demand or invent exact unknown future results.

Every positive-probability operational history must meet demand, material/stage capacity, original commitments and settled-cash requirements. For **each** complete supplied input, expected operating cost must be within **1% above the exact optimum available with the same information**. This target is registered before the author computation. Any optimal or sufficiently good policy is acceptable; no particular action flip or author tie-breaking is required. High explanatory points cannot compensate for a failed physical, epistemic or recovery condition.

Also derive a valid comparison where the distribution class is revealed before week0 but future individual test results remain hidden. Explain this advance-information bound separately from a policy that cannot inspect lots: inspection changes physical usable material as well as information. A numerical optimizer status alone is not a rational certificate of the same-information optimum. Explain why your chosen sufficient state retains all information needed for feasibility and value.

Execute the actual actor through the public exercise, preserve both genuinely induced process-loss boundaries and continue the same original keys/receipts/observations. A repeated laboratory request must recover the original result rather than draw a new result. Preserve full original source, journals, wire records, accepted prefix, failures and post-horizon receivables. Rebuild from source; include readable actual figures and an operator handoff. See [OUTPUTS.md](OUTPUTS.md) for the complete wire and delivery contract.

Standard-library native Windows Python is sufficient for online operation. Any correct language/solver is allowed with a declared source entry point and dependencies; scientific/plotting dependencies belong in your own project. Fast correct solutions are allowed. Simulated weeks, reference computation, files/leaves and elapsed lifecycle are not agent useful hours. This exercise provides finite-model/controlled-process evidence, not real-world procurement/financial approval, arbitrary-failure or same-user operating-system security certification.

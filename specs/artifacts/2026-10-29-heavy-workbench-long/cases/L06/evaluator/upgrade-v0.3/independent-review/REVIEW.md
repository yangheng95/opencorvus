## Inspected primitive and its exact scope

`information_policy.py` checks typed positive probabilities summing1, full leaf action coverage, fixed action-vector widths, integer nonnegative complete vectors and equality for every complete observed-history prefix through each decision stage. It is independent of business cost/stock/cash. Using full prefixes correctly preserves earlier observations when later signal strings coincide. The same-name week-prefix convention means actions occur after that week's registered observation; this needs explicit business timing in the full public specification.

The primitive accepts an assigned graph; it does not independently prove that the graph came from the authoritative input, that observations faithfully encode all visible state, or that runtime did not receive a chosen-leaf side channel. Changing the graph to reveal a leaf earlier trivially changes the permitted information set. Thus the complete evaluator must bind its authoritative graph/observations, not let a candidate choose the information partition. Offline knowledge of the finite support/tree, leaf identities and all conditional alternatives is legitimate; only the realized future path is hidden from the execution request. A publicly named tree node is not an error by itself, but passing the actual future leaf ID in a request, environment, path or state before it is observed is a leak.

This treatment agrees with the role of stage nodes, conditional probabilities and node-specific nonanticipative variables in the mature [mpi-sppy multi-stage interface](https://mpi-sppy.readthedocs.io/en/latest/scenario_creator.html). The library is a methodological comparison, not a mandatory implementation, quality oracle or difficulty credential.

## Necessary decisions before full material/runner implementation

1. Publish the precise within-period order: which signal, actual delivery, demand, receipt/cash and availability facts are observed before each order/production action; which facts become visible only afterward. Histories must include all genuinely visible exogenous and physical facts. Two paths with the same L/H label but different already observed stock/arrivals must not be falsely forced to the same action. Conversely the evaluator cannot reveal an end-period quantity early. Micro t2 demand-before-emergency is clear; the richer16-week timing is not yet supplied.
2. Define the sole joint support and conditional probabilities consistently. Unconditional leaf masses must equal products of node probabilities; observation histories/refinement cannot contradict physically visible past facts. Bind complete control vectors to public units/decision identities; the generic constant width check does not know whether a freight switch, order or production coordinate was omitted.
3. Actual execution/restart must use evaluator-held immutable prior actions and exogenous observations to reconstruct authoritative stock/in-transit/cash/commitments. A candidate's opaque internal state is free, but cannot rewrite prior orders or tell the evaluator which hidden leaf occurred. A cold entry may use a precomputed correct node policy rather than reoptimize every stage. Neither optimizer choice, solver call count, reference posting trajectory nor internal state format may be mandated.
4. If altered commitments/state shocks are to be tested, make their admissible scope/public semantics explicit before candidates. For unreachable states, preserve evidence and accurately report current conflict and permitted recovery; do not secretly demand feasibility for an impossible balance, or allow the checker to repair history on the candidate's behalf. State/read-only history input identity needs real process evidence later, not file-name assertions.
5. Distinguish a new legitimate-policy quality lower bound from a clairvoyant comparison. New data require new registered quality evidence; old47380 does not transfer. To attribute a cost difference solely to information, the relaxed counterpart must keep exactly the same physical/cash/terminal/cost conditions and relax only information. A feasible legal UB minus a clairvoyant LB is not an exact expected value of perfect information; without optimality certificates it is merely a bounded comparison. The tiny exact1 establishes one active mechanism here; it does not prove all full-case costs have an information cause. Correct unchanged actions/no value of a signal are allowed.

# Execution and output wire contract (development draft)

Input actor packet format l06-current-operation/1 contains week, complete committed event/action/receipt records, history including the current complete event, authoritative post_week_state and decision_view. Events carry demand/supplier_capacity_volume/plant_capacity_hours. No actual future/path identifier is included. Public possible support paths remain available. Random actor execution must use a fixed declared seed so complete same-information action comparisons are meaningful; randomized tie handling is allowed if evaluated under the same internal randomness.

One actor line is {"format":"l06-action-response/1","request_id":"your stable logical request","action":{"order_lots":[...],"truck_on":[...],"production":[...]}}. Request IDs identify original complete payloads. A replay of the same event/action returns the original receipt; a different payload under an old ID is idempotency_payload_conflict. A new ID cannot repeat a completed week. The host commits the actual event/action/receipt and recomputes all derived state before presenting the next week. A terminated actor can reconstruct from the supplied complete prefix without storing a particular optimizer state.

The committed-journal export format l06-committed-journal/1 contains committed plus derived state/weeks. It is a logical export, not by itself proof of real execution. Actual testing separately captures programme source/native argv/input-output transcript, commit boundary/exit and original receipt recovery. A deliberately invalid action returns a neutral week/business diagnostic, never a hidden actual leaf name. Preserve original failed attempts and completed rows on restart.

Mandatory deliverables: submission.json and all source/dependencies; complete policy.json; source-map and explanation; per-path weekly-ledger.csv; complete commitment-policy.csv; report with actual figures and operational recovery/reproduction instructions. Exact finite decimal numbers or exact rational strings are acceptable for derived monetary values; action tensors use strict JSON integers, never bools. Equivalent complete JSON/tables/closed formulas may carry explanations without duplicating every value in prose. Final frozen schema, perturbations and grading metadata remain pending.

# 海运库存与船队调度研究任务草稿

尚未冻结，也没有新候选或新成绩。本草稿对应已经实际研究的原问题，不能作为数小时难度或区分度已成立的证据。

## 工作目标与原料

为同一组港口、船队和生产/消费需求交付可执行的调度优化程序、可解释的运营计划及研究结论。研究应回答：哪些航线、等待、船类配置与港存决定了损产/缺货代价，所提方法相对成熟通用算法改进了什么，以及哪些结论仍无证据。

正式数学对象为[MIRPLIB原站](https://mirplib.scl.gatech.edu/index.php/instances)发布的Group2原MPS，采用已在首次本机运行前选定的三个120期实例：

- LR1_DR02_VC01_V6a_t120
- LR1_DR02_VC05_V8a_t120
- LR1_DR03_VC03_V16a_t120

原[模型说明](https://mirplib.scl.gatech.edu/sites/default/files/Group2_MIP_Model.pdf)与data-only文件提供语义背景。原data-only有360期，不能覆盖或替换所选120期MPS。输入由[当前获取程序](fetch_originals.py)从原公开URL获取；第三方许可未核清，仓库不重新许可或托管其原数据。没有公司交易日志的来源声明。

## 必须完成的工作

1. 说明原模型与运营含义，给出实际港口/船类/初始状态、原时间范围和经济目标。分清允许的损产/缺货与硬约束，以及模型未描述的现实风险。
2. 实现可由新原输入运行的优化程序；允许直接使用成熟求解器和成熟算法，也允许有依据的领域方法。不得通过关闭成熟工具、重复计算、人为等待或扩大实例制造工作量。完整数据、代码、依赖和命令须能说明每份结果如何产生。
3. 保存每例原完整变量、实际运行参数/开始终态/日志、真实可行解改进事件及界。无解、超时、未证最优和设施失败分别记录；没有发生的阶段保未执行，不能用最终输出反填历史轨迹。
4. 提供可用的船类航段表、类流的匿名船路径、逐港逐期库存/泊位账和成本分解。保原变量/时间索引，使运营表能回到原模型；同类流不保证唯一的原船身份。
5. 完成有科学作用的比较与解释：成熟算法对照、方法改变的因果依据、真实质量随投入的变化、失败和适用范围。公平资源安排和比较方案须在新实验前声明，不能看过结果后选择有利时段、删除差计划或倒填阈值。
6. 交付可读报告、实际图、源映射、依赖说明和原生重现命令。图要由实际数值生成并真实查看；文案完整本身不等于优化质量优秀。

## 输出合同

允许正常的等价语言与文件布局，不要求作者文件名。交付需明确指出以下对象的位置：

| 对象 | 可执行的含义 |
| --- | --- |
| 优化程序与依赖 | 从原输入生成新结果的真实入口与声明环境，包含实际使用的第三方依赖 |
| 完整数值计划 | 原MPS每个变量的有限实数值、原生目标声明与对应原输入身份 |
| 运行事实 | 实际参数、自然终态/错误、原日志及实际改进事件；时间范围和观察开销明确 |
| 运营计划 | 原弧及整数数量、源/等待/载货/空返/终点退出、匿名类路径，覆盖全部正流 |
| 库存账 | 全部原港口与120期的期初/生产消费/服务/alpha/期末、泊位与残差 |
| 经济账 | 载货/空返、初始港费、损产/缺货、终点调整与原常数，同原目标闭合 |
| 科学报告与图 | 实际结果、方法比较及失败、原界和公开数值的证据强度、运营含义与限制 |
| 移交与重现 | 自含源映射和真实命令；不能依赖作者的旧权重、旧输出、私有路径或未声明缓存 |

当前[运营导出程序](export_operational_plan.py)已经对三份实际已闭合计划运行，能导出这些运营表；它本身不优化、不替代完整研究程序。

## 数值质量与有效性分开

原约束、界、整数性及目标由原完整MPS重算。可行性是成果有效的条件，不能把差但可行的方案当错误，也不能把合法损产/缺货改成隐藏的零损失约束。工程完整性与原件身份只支持结果可信，不给经济质量补分。

经济质量保留每例原最小化成本、真实改进轨迹、界的来源及未闭合差距。原站公开数值只能按其精度和证据强度引用；网页中的相同舍入目标/界不是本机独立最优证书。优秀成果应有真实更好的运营决定、可解释的研究发现和可复现的作用证据。

**本草稿不规定新的100分聚合或“进入某个观察后阈值即可全满分”。** 仍待强弱但均正确的方法锚点、合理可达质量和完整研究对照，才能事前制定并集中审查正式质量标尺。原0.4所有合同和100分只读；本草稿没有重写旧分，也没有保证没人能得到满分。

## 当前研究边界与尚缺项

三例成熟算法首轮、原完整解质量轴与运营交付已有原生证据；两个多类实例还已执行一次整类对方法与全模型热搜索的成对比较，得到真正更低成本的正确方案。它们均未证原全局最优，也未取得未知输入泛化、候选区分度或有效数小时证据。原料构造器现已与三份原模型完整比较，两个预登记合成新输入也已由raw开始实际跑通模型、求解、方法与运营账。它们是披露的构造验证，不能以后再称private未知输入。正式未知输入合同与质量标尺、整题同checker错误programme和一次集中整题独审仍待。当前不能开启新candidate、机械0.5或重复已完成的基线/资格/旧独审。

## 新构造输入的研究范围

[本轮构造验证](constructed-input-study/README.md)已完成。原公开实例仍以各原MPS为数学事实；新构造输入以明确提供的raw、公开构造语义及由其生成的MPS为单一对象，不能再拿一个隐藏平行模型扣分。完整三原模型等价支持当前构造语义，不宣称任意未覆盖原格式/船队/时域皆已验证。

已登记两新输入只是需求循环改变，未增加规模。它们的正确计划仍有显著可改进经济质量，但两份原料今天已披露，不能拿其后来fresh结果证明未知输入泛化或有效数小时。新输入执行提供完整程序路径证据，尚不定义新的满分线。

alpha是原模型允许的有价松弛；非最优可行解不保证所有松弛在物理上必要。当前输出应如实记账并分析改进原因，不能添加满/空库存限定或零缺货等隐藏规则。原人工退出服务和初始港费等来源语义保持。

# 便宜实验优先：暂停与低成本实证

用户明确要求“从便宜的实验开始做”。`pause-receipt.json`保存逐一核验自有CID/镜像/挂载后的六容器可逆暂停；`paused-state-observation.json`另核对实际State.Paused。没有关闭用户进程、重启Docker/WSL或把暂停标成数学失败。

暂停保留运行内存和已有磁盘文件，**不是新生成的完整持久checkpoint**。raw训练seconds在以后恢复时会包含暂停区间，不能算有效训练；后续测时必须扣除已观察暂停/恢复区间。不要因旧Recall“继续长跑”自动恢复全部。

`pinn-early-120-endpoints.json`从已存权重每题约.3秒独立重算，`early-120-exports/`保留实际8数组。只是早期端点，不是暂停瞬间的模型、末态、可达质量底线或候选得分。

新实验顺序为秒级定义/必要条件/手算→可穷举小闭环→分钟级代表验证→有明确问题和增量成本的必要长跑。无总token/总墙钟截断，不压资源或等待凑时长，便宜也不能代替最终质量。

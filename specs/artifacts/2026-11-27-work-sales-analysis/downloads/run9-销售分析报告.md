# 销售分析报告

## 来源与范围

本报告直接读取当前项目根目录真实文件 `sales.csv`，覆盖其中全部 **5 笔原始记录**，未使用现有脚本或旧报告的结果代替复算。源文件字段为：订单编号、区域、金额、备注。源数据没有日期范围或币种信息，因此本报告不推定统计期间及币种。

配套应用内表格为 **《销售订单完整明细》**。每笔原始记录对应一行，初始顺序与源文件一致；“原行序”从首笔数据记录起按 1 至 5 编号，不含 CSV 表头。订单编号、区域和备注按原文保留，金额为可数值排序的数值，“退款”为真正的布尔值，仅在金额小于零时为 true。金额数值显示为 10.1 或 0 时，分别等同于 10.10 和 0.00，不影响金额含义。

## 统计口径

- **总订单数**：按 CSV 原始数据记录逐笔计数，退款和零金额记录均计入，不做去重或剔除。
- **净金额**：所有记录的带符号金额之和。正金额增加净金额，负金额作为退款扣减，零金额不改变净金额。
- **退款笔数**：金额严格小于零的记录数，不以备注文字判断。
- **零金额笔数**：金额等于零的记录数；计入订单数，但不计为退款。
- **区域汇总**：按原始区域名称分组，采用与总体一致的计数及净金额口径。
- **金额精度**：从 CSV 原始金额文本以十进制定点精度独立累加；报告金额统一保留两位小数，精确到分，不使用表格显示值的二进制浮点求和作为统计依据。

## 明细与汇总核对

完整明细为 A001、A002、A003、A004、A005，共 5 笔，与源文件逐行对应，无遗漏或新增。

- 华东：A001 10.10 + A002 20.20 − A003 2.05 = **28.25**，共 **3** 笔。
- 华南：A004 0.00 + A005 7.35 = **7.35**，共 **2** 笔。
- 区域合计：3 + 2 = **5** 笔；28.25 + 7.35 = **35.60**。
- 按金额性质核对：37.65 − 2.05 + 0.00 = **35.60**；3 笔正金额 + 1 笔退款 + 1 笔零金额 = **5** 笔。
- 唯一退款为 **A003**，金额 **-2.05**；唯一零金额记录为 **A004**，备注为“免费样品”，金额 **0.00**。

## 面向销售经理的解读

华东净金额为 28.25，高于华南的 7.35，是本文件中净金额的主要来源。华东有一笔退款，已在净金额中扣除；华南有一笔免费样品记录，计入订单数但不贡献净金额。样本仅有 5 笔且未提供时间、成本或目标数据，不能据此判断销售趋势、利润或目标达成情况。

# Chat 文件交付体验产物

对应[调查与验收记录](../../records/2026-10/2026-10-25-chat-file-delivery.md)。所有截图由本agent在真实开发服务`/ui`操作后实际呈现并人工复核，没有UI自动化测试。使用无敏感合成工时输入，原Chat实际流式gpt-6.1-sol生成文件，修复后继续读取同一Chat和原文件。

- 01：原中文CSV上传完成和真实请求草稿。
- 02–03：修复前报告/CSV已能打开，但工具栏只有写回保存、重载、关闭。
- 04–05：修复后报告/CSV的新下载按钮，实际下载原文件。
- 06：当前未保存草稿下载，dirty状态保持。
- 07：原附件Sources只读阅读，下载保留原中文文件名和CRLF。
- 08–09：中文草稿及放弃重载后的原CSV，标签、状态和内容正确。
- 工时输入.csv、周报.md、工时汇总.csv：真实浏览器下载，与原上传和实际生成文件逐字节一致。
- 草稿样本.csv：实际下载当前编辑器文本，原项目文件保持。
- verification.json：真实请求、下载字节、类型/语言/文档/构建、库保全与关闭的安全摘要。

范围为完整加载的普通文本，包含空文本与未保存草稿；未扩展二进制原文件下载或Markdown预览。初次after复制遗漏附件物理namespace已补齐后重验，不将该准备故障记作生产bug。秘密和完整私有日志不进入本目录。

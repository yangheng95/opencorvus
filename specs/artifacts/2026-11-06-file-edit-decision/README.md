## 真实过程

- 01–03：临时源码输入、包含未保存编辑的预览、磁盘/草稿比较，原保护行为正确。
- 04：从比较返回预览；不是未保存决定弹窗证据。一次旧观察节点点击落在预览区域，重新读取当前状态后正确操作，没有将其误判为产品缺陷。
- 05–07：关闭、重新加载、切换文件的原始决定。“取消/放弃/保存”未完整表达保留草稿及保存后继续原操作的含义。
- 08–10：取消保留草稿；通过“放弃并重新加载”恢复原内容，关闭后重新打开。
- **11–13：英语后态**，实际显示 Keep editing、Discard changes、Save and continue；重新加载时显示 Discard and reload、Save and reload。按钮完整可见，继续编辑保留同一输入，放弃并重新加载恢复原文。
- **14–16：中文后态**，关闭/切换时显示“继续编辑、放弃更改、保存并继续”；重新加载时显示“继续编辑、放弃并重新加载、保存并重新加载”。文字、实际路径和按钮均可读。
- 17–18：实际放弃中文草稿后切到来源，再次打开原交付，内容仍为原版本。
- 19–21：真实较长历史路径的确认、实际放弃并关闭、重新打开原历史文件。当前摘要六条未关闭与历史摘要七条未关闭保持区分，原文件身份和内容均保留。
- 22–25：最终代码的真实磁盘比较、关闭比较后同一临时草稿、放弃决定与重新加载原文，补齐方案要求的修改后比较回归。

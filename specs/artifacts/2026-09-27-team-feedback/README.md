## Business obligations and feedback evidence

It reads original artifacts and messages without changing their scores or bytes.

The feedback result is classified using the actual trace:

1. **Not triggered:** no material error is established in a delivered result. A correct ordinary delivery is not proof of repair.
2. **Missed:** a material discrepancy exists but the team does not independently identify it.
3. **Not acted on:** the team identifies it but no concrete evidence-bearing continuation reaches the original responsible worker, or no actual correction follows.
4. **Correction unverified/failed:** work changes, but the current-result review is absent, still wrong or loses correct earlier work.
5. **Observed complete repair:** a specific original claim, independent counterevidence, same-Task/original-worker continuation, changed immutable result and subsequent target-bound review demonstrate correction while preserving other obligations.

Reviewing a brief does not automatically review later report claims. Reusing the existing reviewer Session is not fresh-context independence.

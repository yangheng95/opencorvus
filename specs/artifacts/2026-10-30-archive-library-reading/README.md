# Read original records from Archive

Settings → Archive now has an explicit **Open** action for retained Chat/Work,
Task and Mission records. It opens original history while leaving the record
archived. Restore and permanent deletion remain separate actions. The button
uses the existing navigation lifecycle and a localized accessible name containing
the original title. Reopening the current ready record also closes Settings,
under the existing API authority and selection epoch.

The missing entry was confirmed on the real before page: clicking the Task title
left Archive unchanged, and the only row actions were restore/delete. The after
page uses ordinary build `main-C9ybhFm-.js` and the same native development server
entry point. No UI automation tests were added or run.

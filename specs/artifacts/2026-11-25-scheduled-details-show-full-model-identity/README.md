# 定时详情模型标识的桌面证据

两个自有规则使用相同服务商和前缀、不同模型后缀。另有两条未来规则分别使用全局和项目默认设置。

- [全局 East 规则的模型显示](baseline-east-model-truncated.jpg)。同一格只显示服务商的一部分。
- [项目 West 规则的模型显示](baseline-west-model-truncated.jpg)。字段显示与 East 相同的截断前缀。
- [真实字段观察](baseline-model-field-observation.json)和[实际规则读取](baseline-model-definition-receipts.json)包含两个确切原标识、实页格宽及四个真实定义。

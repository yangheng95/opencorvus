# 销售报告

## 统计口径

- 每条 CSV 数据记录计为一笔订单，不按订单编号去重；退款及零金额订单均计入订单数。
- 负金额为退款，直接抵减净金额；零金额不改变净金额。
- 金额使用 Decimal 精确累加，不逐笔舍入；总计和各区域分别在输出时按 ROUND_HALF_UP 四舍五入至两位小数。分区显示值相加可能因舍入与总计相差一分。
- 按原区域名分组，不去空格、不规范化；JSON 金额为两位小数字符串。
- 输入使用 UTF-8（兼容 BOM），按标准 CSV 引号、逗号和换行转义读取；不修改原 CSV。
- 无效、空白或非有限金额（NaN、Infinity 等）使整个统计失败：接口抛出 SalesDataError；命令行向标准错误输出“错误：”及行号，以状态码 2 退出，不写入统计输出。

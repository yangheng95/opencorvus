# 网络监听参数验收证据

- `baseline-runtime.json` 记录实际给定的网络参数、冲突的隔离配置、真实启动回执和服务请求结果。
- `baseline-network-options.png` 是本人在 Windows 中打开基线回执地址后查看的真实附件。地址栏显示配置文件端口。
- `candidate-runtime.json` 和 `candidate-checks.json` 记录明确参数的实际启动、会话和原件请求与下载核对。
- `candidate-network-options.png` 是本人查看候选回执地址和展开后正文的真实桌面截图。
- `candidate-sdk.json` 记录 SDK 实际服务地址、health 和正常关闭。
- `runtime-audit.json` 记录只读数据库结算与本机流式请求事实。

参见 [本批规格](../../records/2026-11/2026-11-19-cli-network-option-precedence.md)。

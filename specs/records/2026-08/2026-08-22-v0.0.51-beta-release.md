## Release boundary

This release carries the product prompt/package behavior that closes authority-source discovery and requires source-derived entity/rule/effect action matrices across Base, Advanced, and generated Expert Squad templates. It must not carry the benchmark adapter, evidence catalog, dispositions, dashboard, experiment Skill, or dated benchmark analysis record.

The release authority is reviewed product commit `0ac8384a`, whose exact paths and generated Base/Advanced/package-template revisions are independent of benchmark-only changes. The source branch is `v0.0.50beta`; the application version becomes canonical SemVer `0.0.51-beta`, the product label is `0.0.51beta`, and the only release tag is `refs/tags/v0.0.51-beta`. After the immutable release is verified, publish branch ref `refs/heads/v0.0.51beta` from that release commit as the next beta maintenance line; the compact product label must never be created as a tag.

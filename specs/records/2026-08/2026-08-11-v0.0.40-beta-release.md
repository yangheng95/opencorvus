## Problem depth and impact

- Observable state: the integrated source is still versioned `0.0.39-beta`; the requested release identity is `0.0.40-beta`; the target tag is absent from the last successful remote query.
- Direct trigger: the user explicitly authorized both the version mutation and the external tag-driven Release workflow.
- Data and control flow: the version synchronizer updates every current metadata consumer, then the pushed immutable tag becomes the sole source checked out by all ten native matrix rows. The workflow—not local artifacts—is authoritative for signed installers, portable archives, the GitHub prerelease, and `desktop-update-beta/latest.json`.
- Stale-path risk: the remote advanced while local reviewed commits were awaiting push. The task therefore fetched and merged `origin/main 999eb4cc34607c7f5ddf8c8457b69099cb921893` before any bump; tagging an older commit or manually dispatching stale `main` is excluded.
- Failure handling: any non-fast-forward source push, existing mismatched tag, missing/invalid signing secret, failed native row, incomplete asset set, or unverified update manifest prevents a completion claim. No fallback workflow or replacement tag is permitted.

## Execution plan

1. Synchronize the release family with `bun run version:bump -- 0.0.40beta`, verify all declared consumers and MSI `0.0.40.0`, and inspect the exact source diff.
2. Run focused release/version contracts, typecheck, documentation, diff, secret, and real local Overlay build checks without UI automation.
3. Record artifact/source evidence and obtain an uninvolved read-only review; repair and repeat until no unresolved finding remains.
4. Commit the reviewed release delta, successfully refresh `origin/main`, audit the complete pending set, and push `main` without bypassing hooks.
5. Confirm `v0.0.40-beta` is absent, create one annotated tag at the exact pushed `main` SHA, push only that tag, and identify the resulting canonical `build.yml` run.
6. Monitor the workflow to terminal state and verify tag/source agreement, prerelease state, complete release assets, signatures, and the beta desktop update manifest.

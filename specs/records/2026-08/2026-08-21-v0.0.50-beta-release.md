## Root-cause and release scope

The Expert Squad skill projection had two inconsistent enumerations: the resolver allowed the scheduler-owned `universal-build` worker to resolve package Skills, while the public mount matrix enumerated projected package workers only. Advanced could therefore dispatch an external-system task directly to a generic worker whose effective Skill mount was absent from the evidence surface. The repaired single source enumerates both scheduler-only and package-projected workers, marks package versus platform capability ownership, and makes the package prompts bind external mutations to a planned-delivery workflow with independent verification.

The benchmark runner's coverage seal and catalog/verifier changes remain benchmark-branch evidence infrastructure and are explicitly excluded from this release. This release carries only the product behavior, generated package revision/catalog projections, and their positive tests.

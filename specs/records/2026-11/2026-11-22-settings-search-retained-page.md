## 实施前证据、根因与影响

2026-11-22，在独立的 `settings-review` 工作目录及专属运行目录启动基线，启动回执、监听进程、项目及实际 `/ui/` 和脚本请求均已核验，基线脚本为 `main-CXavjC5-.js`。在 General 打开时输入 `proxy`，General 和 Network 同在 Application 分组，仅显示原有选中底色。按下方向键直接聚焦 Network，按 Enter 才真正打开它。Network 成为实际匹配的当前页后，General 消失。再输入无匹配查询，左侧同时出现无结果文字和一个仍可见的 Network 选项，其保留原因没有可见标识。没有操作凭据、代理设置或外部请求。 [基线截图](../../artifacts/2026-11-22-settings-search-retained-page/README.md)

匹配列表从 `CONFIG_SECTIONS` 的当前语言元数据和查询派生。侧栏有意将活动页加入可见集合，以维持原触发器和面板生命周期，但两个现有行渲染分支只使用最终可见性，丢失了命中与保留的区别。方向键入口已用真实匹配集合，所以键盘行为正确，输入提示和无结果提示也都有准确契约，早先修复无法表达保留行的来由。根因属于呈现层，未观察到调度、执行轮次、队列、唤醒、恢复或终态异常。

保留规范分组、共享 Tabs 触发器身份、可见行顺序、Tab 面板关联和键盘返回方式。让实际匹配集合同时驱动搜索焦点和活动行状态，复用一个侧栏选项渲染函数，在仅因活动状态保留时增加简短的本地化说明。说明与该行的无障碍描述关联，选项可访问名称继续取页面名称。两类导航行都复用原有图标及徽标锚点。新增说明可换行，常规行继续使用原有行密度。风险为提示错加给已命中行、重建触发器导致焦点或录入丢失、窄侧栏截字、本地化遗漏及对产品信息行的影响，均纳入实际桌面观察。匹配算法、命令面板、打开页面的控制流、公共接口、持久化、权限和模型执行没有本批变更。

## 实施与验收

普通分组和产品信息行复用同一侧栏选项渲染。活动页仅在未匹配时显示状态说明，说明绑定为该行的无障碍描述。匹配集合同时用于侧栏可见性和搜索框方向键路径，继续保留活动页原触发器。

实际候选脚本为 `main-Cjs6aoUc.js`。在 1280×720 英文桌面，`proxy` 将打开的 General 标为 Outside search results，↓ 聚焦 Network，Enter 打开该页并显示常规选中行。无匹配时，↑ 留在输入框，Network 仍打开且带有说明，Escape 清除搜索并恢复常规分组。通过设置分隔器 Home 缩到最窄，About 的英文提示完整换行，点击 Network 正常打开。简体中文的窄栏搜索「代理」时，「外观」显示「不在搜索结果中」，↑ 聚焦「网络」，点击进入，使用搜索清除按钮恢复分组且「网络」仍开启。保留页内容在过滤、聚焦和清除时均持续可见，未输入面板字段或操作网络设置。未执行读屏、输入法组合或跨浏览器验证。候选 About 显示并行准备中的 0.1.52 开发版本号，本批验收只涉及设置侧栏。 [13 张已人工复核的桌面截图](../../artifacts/2026-11-22-settings-search-retained-page/README.md)

聚焦检查通过。`bun run typecheck`、`bun run check:i18n`（2 个语言，3239 个键）、`bun run check:css-tokens`、`bun run build`（2 分 18 秒，含渲染器公共面）、`bun run docs:check`（353 项操作，26 个分组）和 `bun run check:architecture-index`（20 份当前文档）均通过。启动和结束核对专属运行首页、实际入口脚本及空 Mission 列表，两套页面关闭，服务均正常关停。隔离库里的会话、消息、执行任务和两类模型供应商活动计数为零。

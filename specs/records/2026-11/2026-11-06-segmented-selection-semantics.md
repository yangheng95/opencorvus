## 根因和完整影响面

当前共享包装的 value:T 是必选值，handleChange 拒绝 null（空选择），八个调用文件都保持一个真实当前选项。但是包装使用 KobalteToggleGroupRoot；安装 NU6GTUW4.js 固定 disallowEmptySelection=false（允许空选择），H6DSIDEC.js 的 Escape 会清空库选择并 preventDefault（阻止默认事件）。业务拒绝空值后画面仍选中，外层弹窗也收不到 Escape。点击已选项同样先产生取消选择请求再被拒绝；只有结果被留下，底层交互协议仍然不一致。旧 primitive 收敛删除了重复键盘激活，但未替换不匹配的切换组，991 只修来源关闭动作，与此独立，不改共享 Dialog 的退出合同。

全部调用为：FileEditorPane 源码/预览与三个比较版本；FileChangesView 五类文件状态筛选；ConversationTurnControl 多模型用量筛选；MissionBoard 列表/看板；MissionCreateDialog 创建方式（立即开始/保存草稿）及多步任务类型；PermissionsPanel 当前授权模式；UsagePanel 时间范围；ScheduledAutomationsPanel 状态与来源范围两个独立筛选。都是受控单选；创建的工作类型用空字符串刻意表示尚未选择，用户选过后不允许通过取消选项回到空值，不能替用户补默认类型。FileChangesView 唯一使用 onActivate 重复激活和 itemAttributes（data-ui/status/size）；全仓没有这些属性对应的按钮类型查找依赖，相关 CSS 位于 changes.css。其它表面 CSS 为 usage、workspace、mission-board、automations、chat-bubble；仅 changes/usage 和共享样式依赖 data-pressed/键盘焦点样式，需要随官方 radio 的 data-checked 与真实输入焦点同步替换，不保留旧属性兼容双源。

已装 SegmentedControl 根基于同一 RadioGroup，Item/Input 沿现有 FormControl 产生同组 name，其 name 默认为当前唯一组 ID，各实例无需平行命名配置。原生输入维护实际选中及禁用，Item 派生 data-checked/data-disabled。与仓库现有原生 Radio 包装一致，可让 Item 用真实 label 包含 Input 和原 JSX 文本，保持整个原选项的点击面积、真实无障碍名称和禁用行为；输入绝对隐藏时 Item 必须 position:relative（自身定位），不让键盘焦点滚动页面。

方案只替换唯一 SegmentedControl 当前实现为已安装的 @kobalte/core/segmented-control Root/Item/ItemInput，沿原 value/onChange/ariaLabel/size/class/option 元数据；删除旧 ToggleGroup import 和 nullable（可空）协议。Input 的真实 click 消费现有 onActivate 一次，文字区域由 label 原生激活同一 Input；不复制选择、不手动设置 checked、不注入键盘或全局 Escape 旁路、不改库。保留 title/disabled/tone/data-value/itemAttributes/renderOption，全部由原调用者提供，不新增界面文案或本地化键。

共享和 changes/usage 样式将当前 data-pressed 改为官方 data-checked；焦点环从不可聚焦的外观元素转为其实际 Input:focus-visible，使用当前项目已采用的 :has 选择器。旧 button 专用 disabled/highlighted 选择器同步移除，不留下旧切换协议。字体、密度、边距、颜色、尺寸和模块顺序使用现 token（设计变量），不得借语义修复重新设计页面。真实前态若证明 Home/End 等已有能力，实施前补齐其保留决定与风险；不把库名称或静态类型当作行为验收。

主要风险为选中样式/计数变暗、隐藏输入缺少定位引起页面跳动、label 点击与输入事件重复激活、原生组串扰、原表单误提交、焦点环丢失、长模型名排版以及禁用选项可操作。用同一成熟 primitive 和唯一受控值、局部输入身份与原函数/原始元数据处理；必须真实核对比较 Escape、重复选中、方向键/空格/Tab、普通页面/模态与两个同页实例、原计数与中文控件/提示、原草稿/文件及关闭返回。

权限页只阅读和激活已选的当前值，不修改授权范围或原项目配置；创建表单只暂填/切换再取消，不提交任务或模型请求。用量多模型控件需自然真实案例；957/用量记录说明旧数据只有一个模型，当前存在性待只读核对，不造消息/账本/fixture（夹具）或为填案例调用未授权模型。缺少自然多模型或实际禁用过渡时必须标明没有新增视觉资格，不能以类型通过冒称覆盖。

这是纯界面交互/样式合同；不修改后端、接口、权限策略、schema、模型、执行调度/队列/唤醒/恢复/终态。非 UI 正向验收保留完整原公共/持久事实，不新增镜像 UI 的自动化测试。若发现执行异常立即按共享机制横向审计全部入口/轮次/恢复/串并行/多项目；当前没有该证据。

## 方案

为当前项目内已打开文件，在现有文件头工具组提供「Show containing folder in Explorer / 在资源管理器中打开所在文件夹」的共享图标按钮。以当前正式文件目标的规范相对路径计算父目录，根级文件对应项目根。核对当前项目身份，使用现有 `requestFileExplorerFolder` 携带同一 API（Application Programming Interface，应用程序编程接口）连接与选择轮次和真实焦点来源；`main.tsx` 仍负责切换右栏，Explorer 完成目录读取、清除搜索、选定目录与焦点，或呈现真实读取失败和重试。文件仍保留自己的右栏标签与草稿，目录动作无需准备切换编辑器目标。相同父路径规则仅在需要时共用现有工具，保留主机文件名中的合法字符。外部绝对文件来源沿现有展示。

候选用同样的北区搜索打开文件，添加一行未保存文本，以键盘或鼠标执行所在目录动作，检查真实目标行、目录焦点、已有文件读取和当前连接。返回原文件核对草稿，撤销并确认无写入；切到同名南区测试另一语言、相同相对路径及实际原文。通过根文件复核根列表与搜索焦点。桌面以现有右栏宽度为主，检查最窄右栏中的实际控制组。若复用或调整共用路径计算，增加对应聚焦正向规则检查。运行文件服务聚焦检查、类型、双语、正常构建、文档及架构索引。

## 实施及验收方案

在现有日志工具中从 server 来源和服务端结构化 data 识别有可核对身份的实际中间件请求，取 method、path、status 与实际响应码。识别基于明确字段和状态，不通过原始文本关键字猜测。不重新解析原行，不拼接第二份记录。折叠主文显示实际方法、路由和当前语言的开始／已响应／失败；响应包括实际数字码，4xx 表示真实响应而非传输失败。当前请求的原生详情摘要以可见动作名加同一主文作无障碍名称。搜索从同一个派生主文查找，同时保留已有匹配字段和原值。非此结构的日志保留自己的真实主文、摘要和详情。公开原文、结构化 data、导出和复制内容保持记录格式。

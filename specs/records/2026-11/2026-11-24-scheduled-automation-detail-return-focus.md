## 可观察现象、根因及范围

真实独立 `40970/ui/` 加载 `main-Cx1AsT5o.js`。英文 100% 用 `receiving` 筛出北门、西门、场院三条真实计划。从输入 Down 两次聚焦中间的西门，用 Enter 打开实际详情，正文是 `Check the west dock receiving manifest.`，焦点在定时任务返回按钮。再按 Enter 回到同一列表，输入框获焦，随后 Down 跳到排首的北门。用户在关闭详情后失去原来的浏览位置。上一批也在中文 160% 路径复现从第二条返回时聚焦搜索。 [原始截图](../../artifacts/2026-11-24-scheduled-automation-detail-return-focus/README.md)

打开详情时记录活动的实际行节点。返回详情把选中和草稿状态清空后启动正式列表重读。`load()` 同步置为加载状态，列表的条件渲染立即卸载所有结果行，先前保存的节点失去连接。紧接安排的旧归焦只保有节点，节点已卸载时只能在当时可用的搜索框归焦。服务读回后生成当前真实按钮，又没有再以原定义的身份完成归焦。上批接通了搜索与相邻结果导航，保留这条详情重读路径，所以问题可见且仍在。

本次影响限只读详情返回到相同列表，关联当前搜索、筛选和可操作结果。读管道已有单一取消控制器，详情、初始读、错误恢复、编辑回执、变更状态和删除后重读通过各自原有调用持有该请求；到期列表读取为背景只读，按当前显示状态更新数据。运行历史有独立读取及当前 ID/连接归属，此次数据库回读的四个定义、七次修订、远期时间及空历史与输入一致，没有执行、轮次、队列、计划唤醒或终态异常。编辑取消回详情、清除筛选、重试焦点、作者或删除触发器和正式服务接口沿各自当前行为。

## 实施和验收

详情返回把实际详情中的计划 ID（标识）传入现有列表读，以该请求的权限所绑定的连接和退出详情时的 ID 为准。仍在重读时向现搜索框交接，保持键盘可用。读结束、行已重新呈现后，仅在该请求与面板仍拥有焦点交接时重获相同 ID 对应的启用按钮。保留当前输入焦点和用户已采取的键盘、指针、编辑或离焦操作。若同一 ID 在当前接受结果中不可见或不可用，现输入焦点可继续用于搜索。已挂载行把同一真实定义 ID 写到自身属性，供作用域内识别，不做位置或名称推测。等待与清理由现有请求和焦点机制管理。当重读失败时沿用既有错误与保留数据语义。

验证英文从中间一条实际详情返回原行，再继续相邻浏览，中文 160% 核对过滤和可见焦点，从鼠标及键盘触发打开和返回。对实际已暂停过滤，用同一隔离服务正式状态更新让一个计划移出该结果，返回到可编辑搜索并核对其余行、定义身份、新修订和无运行数据。复核创建取消和编辑取消走现有焦点路径，检查同一数据目录和实际请求，以及有必要的聚焦正向用例、类型、双语、样式、构建、文档、架构、提交和推送。

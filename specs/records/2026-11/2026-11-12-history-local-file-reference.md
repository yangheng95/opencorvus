## 实施与验收

历史文本 `FilePart` 的有效 `file:` 引用使用当前语言的「阅读当前文件」动作，以所选会话目录和本次 API 归属交给既有绝对来源工作台。该工作台读取当前文件并保持只读，已保存消息正文可在原位置核对。按服务器路径语法转换 Windows 盘符、网络共享和 POSIX 路径，保留单次百分号解码和真实文件名；用已有 `server-path` 数据测试覆盖正向身份与明确无效输入。真实页面同时复核带空格路径、当前文件内容、文件下载、缺失文件的既有工作台反馈、语言和显式附件。另核历史数据库没有新增会话消息或模型请求，两个隔离服务关闭，完成类型、双语、样式、构建、文档与架构检查。

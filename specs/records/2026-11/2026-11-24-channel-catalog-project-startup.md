## Recall

用户要求本人独立持续按批改进 OpenCorvus。每批先落盘根因和影响，实施、真实桌面操作和人工截图复核、聚焦正向测试、范围提交、合并上游和正常推送。`b184d61ae` 已推送，主分支与远端一致，保留 177 项工作区状态。已读 `ChannelRoutes`、`ChannelRegistry`、`ChannelSupervisor`、`InstanceBootstrap`、配置接收与通道运行同步、目录前端唯一加载器、通道设置与读取失败重试、[独立配置结算](2026-11-10-project-config-and-channel-read-settlement.md)、[目录重试](2026-11-10-channel-catalog-read-retry.md)和[面板合同](../../current/architecture/07-panel.md)。全仓核对 `channel.list`、`GET /channel`、`ChannelRegistry.list`、`ChannelSupervisor.sync/status/restart`、`loadConfigInfo` 和真实通道启动检查。只使用自建项目、回环网络和虚构值。无用户凭据、外部通道、消息或模型请求。

## 基线、根因和影响

- `41720/ui/` 加载正式 `main-DPV2Gw9j.js`。真实受保护项目进入设置 → Channel，项目归属和 External access 配置可读，目录失败。打开详情和点击 Retry，两个请求 `6d2fd50d-2d8c-4392-9ef7-c7e71f3c091c`、`9ae0c7a3-b25d-42b0-bf8e-97f3b1c76752` 均在写入现有只读 `.gitignore` 时返回 500 / `EPERM`。直接读取 `/config` 在两个项目都返回 200。普通项目的目录读取返回 200、27 项，既有 IRC（Internet Relay Chat，互联网中继聊天）由本项目配置明确禁用。[桌面和请求证据](../../artifacts/2026-11-24-channel-catalog-project-startup/README.md)
- 另开自建可写项目 `local-matrix`，已有配置启用真实产品的 Matrix 适配器。它通过回环协议夹具完成一个身份请求并进入实际拉取，页面显示 `Configured` 和 `Runtime: running`；直接目录与运行状态均为 200。夹具不发送消息，连接不通往外部服务。这项既有启动行为是保留条件。
- 前端在恢复项目、进入新项目和重试时统一经 `loadConfigInfo` 读取项目作用域的配置和通道目录。中间层把 `GET /channel` 判为完整项目运行权限，先写 Git 规则、安装可执行子系统，再进入目录。设置页能分别显示配置和目录的已接受结果，之前的错误与重试改进无法跳过目录的错误前置。目录本身只根据当前配置描述和同一个 `ChannelSupervisor` 的真实状态投影。完整启动中的 `ChannelSupervisor.sync` 也是冷项目当前已启用通道自动运行的一个入口，直接删掉该耦合会让应用的配置目录在冷项目中丢失启动作用。
- 本次范围限通道目录和该目录承接的冷启动，保留当前配置来源、现用 `ChannelSupervisor` 状态与生命周期队列、配置变更同步、明确运行状态查询、重启、通道入站、项目隔离、结构和双语界面。风险是目录错误仍遮住配置、重复连接、连接状态误报、已应用配置被旧目录覆盖、读另一项目时投影其通道，或压掉真实初始化失败。已有真实故障发生在目录到处理器的准备阶段，未观察到 Task（任务）、Mission（多步任务）、Session（会话）执行轮次、调度、队列、唤醒、恢复或终态异常。

## 实施与验收

把精确的 `GET /channel` 归入已有项目身份权限。保留目录读取同一 `Config.get` 与唯一注册表。让同一 `ChannelSupervisor` 在现有生命周期队列中按当前配置完成第一次本项目通道初始化，再返回真实快照。以现有签名的未赋值表示尚未初始化；已应用的配置、已启动的连接和已结算的错误继续使用同一状态，反复读取目录不重开运行。启动、配置变更和目录共用原同步实现与适配器；已命名的启动失败沿同一运行错误快照展示，其他读错误继续传播。完整项目运行入口及显式运行控制沿现权限。

新增聚焦的正式路由正向检查，真实保护规则、准确配置和 27 项目录，先证明旧版失败。用真实产品 Matrix 适配器和回环协议夹具确认冷项目启动正向、重复目录读取、已配置与需运行的区别，以及不同项目各自的状态。实际桌面复查保护规则下的目录、配置编辑器只读打开、不同配置的普通对照和已启用的回环通道。通过原始配置原文、Git 规则字节和只读属性、真实握手/接收请求、无消息与模型执行的持久事实验收。候选和基线独立退出，范围提交及正常推送。

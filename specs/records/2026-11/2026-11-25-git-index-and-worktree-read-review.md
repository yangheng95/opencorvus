## 分析与影响

- 当前没有已证明的读取缺陷。Git 状态分别计算索引列和工作树列，同一文件可同时贡献 staged（已暂存）与 modified（已修改）；环境栏分别显示两项，未错误相加为去重文件数。`mode: git` 以 HEAD（当前提交）与工作树比较，包括已暂存文件后来的磁盘改动。
- 需要真实确认的风险为：同一文件存在不同索引/磁盘正文时，计数是否准确，差异是否取完整当前正文，原带空格路径是否保持真实身份，环境刷新是否采用当前正式状态；清理自有暂存后原索引和 HEAD 是否保持。不能仅凭一份 Git patch（补丁）或界面计数推断另一数据层的内容。
- 当前默认目录监听和显式刷新仍按原合同；外部 Git 暂存不保证是产品文件保存通知，不能将缺少此通知误判为调度问题。未发现 Task/Mission/Session（任务/多步任务/会话）执行轮次、队列、唤醒或终态异常。本批不改公开接口、存储、模型、配置、分支、工作树或提交历史。

- 使用本人已有隔离 Git 项目 `model-identity-review`，先保存正式 VCS 信息、实际 Git 根目录、分支/HEAD 和全索引语义条目。以仅新建方式写入 `  b648-index ledger.txt`，正文 `B648 staged parcel.\n`，通过无 shell（命令解释器）插值的精确 Git 参数只暂存该新文件，再追加 `B648 later worktree parcel.\n`。不得暂存其他文件。

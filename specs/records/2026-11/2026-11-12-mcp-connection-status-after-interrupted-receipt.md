# MCP 连接回执中断后核对原项目状态

## Recall

- 用户要求持续按批、本人与真实桌面独立验证，先把根因和影响落盘，聚焦正向检查后范围提交、合并上游并正常推送。两个隔离 Git 项目各配置同名本地 MCP（Model Context Protocol，模型上下文协议）`receipt-review`，原持久配置禁用。由实际应用连接只在隔离环境运行的标准输入输出服务，未分配模型工具，未执行任何工具或模型。
- 已读根 `AGENTS.md`、`04-extensions.md` 的配置代际、连接终结和作用域、`07-panel.md` 的连接设置、[现有连接管理](../2026-10/2026-10-28-mcp-connection-current-journey.md)、[状态读取恢复](2026-11-10-mcp-status-read-recovery.md)。全仓查 `MCP.connect`、`MCP.disconnect`、`MCP.projectStatus`、`withRuntimeControl` 的配置和运行入口、`SkillMarketPanel.refreshMcpStatus`、`connectMcp`、`disconnectMcp`、`loadProjectMcpStatus`、共享回执分类和现测试。`/mcp/project` 是设置的当前项目读取，`/mcp` 用于有效配置。

## 根因与影响

1. 隔离实际 `39851/ui` 使用 `main-CeGI01ZW.js`、连接 `39850`。对 `baseline-project/archive-review` 中 `receipt-review` 点击 Connect。真实 POST 200 `31507c45-6dab-4c22-9126-13e8417452be` 的 4 字节 `true` 只交付 3 字节。进程 21096 实际在该项目启动、正式 `/mcp/project` 为 `connected`，另一项目同名项仍 `disabled`。原面板显示 Connected 和 MCP action failed 两条冲突信息。通过页面 Disconnect，真实 POST 200 `b49dc241-6615-427d-a925-4315a7777cca` 同样截断，原进程实际退出，当前项目恢复 `disabled`，页面仍显示同一失败。[截图和真实回执](../../artifacts/2026-11-12-mcp-connection-status-after-interrupted-receipt/README.md)
2. 页面只在写正常返回后显式读回，回执不可读时将传输诊断一律作为通用动作失败。独立状态轮询正确显示当前项目运行状态，却不会清除或改写独立动作通知。客户端服务也没有验证已声明的成功布尔回执。正常拒绝、结果未知和当前状态是不同事实，需要在同一请求边界各自保留。
3. 服务器连接和配置控制复用 `withRuntimeControl` 及持久配置代际，连接验证了实际同代际进程，断开等待该配置的物理清理。项目状态按当前配置身份读取，只能证明观察时该项目名称的状态，不能据此证明丢失回执的旧配置代际或原调用因果。核对设置入口、配置变更、状态轮询、项目初始化与关闭，以及供 Task（任务）、Mission（多步任务）、Session（会话）执行的独立 scoped owner（作用域所有者）和项目关闭清理。实际两笔运行状态和进程正常结算，原配置保持，另一项目没有启动，没有发现执行轮次、队列、唤醒、重启恢复或物理终态缺陷。
4. 改动仅限连接控制回执验证、当前状态读回、项目/连接归属与通知。风险是把同名另一项目或其他配置代际当作当前动作成功、用失效读取覆盖状态、重复写、误报 OAuth（开放授权）认证结果，或让正常状态轮询抢走焦点。API（应用接口）、后端所有者、工具分配、存储和物理清理保持当前合同。

## 实施与验收

- 连接和断开复用现有入口，显式携带捕获的连接归属，验证服务成功回执为 `true`。明确拒绝保留现有错误。回执不确定时，通过原项目状态所有者做一次精确读取，显示读到的服务名、完整项目目录和实际状态，并保留原诊断；只陈述观察状态。该读取没有获得精确服务时，保留回执及读诊断并引导看现有自动重读区域。禁止重发写操作或接纳其他项目的结果。
- 复验真实中英文 Connect/Disconnect 回执截断、同项目当前状态、另一项目同名项、可访问诊断、正常控制和进程物理退出。用真实双失败核对提示和自动状态读取恢复，验证连接 scope 与普通焦点。正式接口校验原响应、不同项目状态和持久配置；核对进程事实、零执行和模型。聚焦连接客户端服务合同、核心运行所有权、类型、双语、构建和文档检查。

## Proposed operational contract for root review

1. Parse the supplied nonblank string, after outer whitespace trimming, with the host's mature absolute URL parser: JavaScript URL in transport-protocol; existing tauri::Url in Rust. Parse **before** stripping slashes or appending a route. Parser failure is a local typed malformed-base error and must not embed the rejected raw URL in its public message.
2. The operational base is HTTP or HTTPS with a nonempty authority/hostname. This selection follows the actual HostTransport HTTP methods, fetch/EventSource use, server startup URL and saved remote/proxy API purpose; it is not inferred from whether ftp/file/data/javascript happened to construct a Bun Request. Other resource/open-url schemes retain their separate existing contracts.
3. Preserve the base pathname prefix, host, explicit usable port and IPv6 address. Append API/resource paths beneath that prefix using URL components, after the current leading-slash handling, instead of raw concatenation ahead of parse. Request-specific query and project-directory injection retain their existing owner. Encoded pathname pieces must remain URL-parser-owned; do not decode/re-encode by hand.

## Failure and impact

The `v0.1.16` macOS x64 desktop row passed after disabling the Rust cache post-save. Its CLI row took 24m40s through successful package validation and artifact upload, then the shared `setup-bun` action's optional `actions/cache@v6` post-save was cancelled by the 25-minute CLI job limit. The cancelled job makes the matrix incomplete despite its uploaded files. The built-in result correctly withheld public publication, updater and website. This is a shared optional cache-finalization risk for long native jobs, not a binary packaging or business-function failure.

The shared setup action is used by release, CI, manual overlay and website workflows. Linux/macOS cache restoration is useful, but automatic post-job saving can make a completed long job fail. Windows already skips this cache; install-disabled callers must not save an empty dependency cache. The release's 40-minute deadline remains authoritative. The next available version is `0.1.17`, because both prior draft/tag identities are owned by their exact failed runs and source commits.

## Analysis

Progress cards have a fixed 188px scaled height, an `overflow-y:auto` event box with `overscroll-behavior:contain`, and their own animation-frame scrollTop writer. This makes the inner card own both automatic and wheel movement. The main Conversation follows its published tree revision and only the agent record count; updating an existing child's activity is not an explicit outer-follow signal. Earlier chrome changes retained those conflicting scroll owners. Replace the inner scroll/height constraint and its writer, keep the canonical bounded 24-item activity projection, and notify the existing outer controller from current-source agent activity changes. Preserve history anchors, virtualization and the operator's tracking state. No scheduling/API/persistence contract changes are needed.

The gallery uses 132px fixed cards, an 86px cropped thumbnail and three metadata lines, while group owner/time/count form one cramped headline. Improve preview scale, group metadata hierarchy, panel insets and thumbnail containment using the existing virtual rows, lazy loading and exact image preview owner. No separate image source or eager full-size loading is introduced.

Popup primitives use inconsistent layers: generic menus/popovers are at 100, dialogs at 10000, selects above dialogs; ordinary scrims are also below persistent title chrome. Dialog header/footer insets differ from body insets. Converge these in primitive styles, add short entry/exit opacity/transform transitions with reduced-motion support and keep opaque readable surfaces. No live blur, perpetual decorative animation or per-frame idle work. Preserve Kobalte focus, dismissal and accessible title semantics; keep drag transforms independent from entry effects.

Search also exposed overlay-size-contract.test.ts, a CSS source-string assertion. Delete this UI automation test under the repository rule; its production sizing generator remains. Native menu readiness and Content Security Policy tests are non-visual contracts and outside that removal. Other unrelated test paths are not expanded.

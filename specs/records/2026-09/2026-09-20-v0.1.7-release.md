Need reproduce deterministically with a real process whose output is consumed after exit, audit every shared facade consumer/adapter and precedence with cancellation/deadlines, then settle the completed run from fully observed output facts without changing immutable physical exit facts. The issue is shared process settlement, not a Work Artifact-specific exception. - Package repair is broken at three shared boundaries: Market availability uses only validated declarations (so isolated packages look absent), Market detail calls loadInstalledCatalogPackage (rejecting the old manifest before returning its exact digest), and Manager publication calls loadPackage on the prior revision (rejecting it before replacement). Recovery likewise classifies a byte-complete old-schema backup as partial by parsing its catalog. Prior tests used current-schema packages named “legacy”, so they did not exercise a genuinely obsolete manifest. Fix provisioning to inspect identity and canonical bytes only, preserve the prior byte snapshot, keep incoming payload/runtime validation strict, and recover from exact journal digests rather than interpreting the backup schema. Backend discovery/ordinary runtime bootstrap remain read-only, so reading a catalog cannot silently mutate packages. Report unsupported schema versions concisely from the manifest parser, using the schema's version literal as authority.

Physical supervisor durable settlement and Task leases remain unchanged.

## Analysis and experiment design

The existing squad has only model-free admission evidence. Unknowns are real tool materialization, executor/verifier handoff, Task completion convergence and model business quality. Runtime tools changed since its creation; verify current definitions and actual requests rather than infer correctness from prompt names. No observed scheduler defect yet; any queue/wake/terminal anomaly requires the shared Task/Mission/Session audit before treating it as squad-specific.

Use `openai/gpt-5.6-luna`, the explicit Luna identity used by prior repository experiments, preserving continuity rather than silently migrating to GPT-6. Current local catalog contains both. Copy the authorized credential and its model catalog together to a newly isolated runtime; never output their values. Resolve Provider model -> actual API model and run the existing streamed preflight before any Task. Use the existing server recovery/Task API, process supervisor and RealProviderAudit; Inspect remains the only benchmark runner.

Inputs: unchanged official case prompts and initial worlds from pinned AutomationBench 1.0.6 revision 4a8e106. Diagnostics: existing finance/sales/marketing smoke manifest (3 cases). Pilot: seeded selection, one case per six business domains, excluding calibration members; freeze membership before reading scores. Tools perform simulated world mutations only. Output: Inspect logs and independently reproduced official scores, per-case terminal/error evidence, Task/Session role/tool/model accounting, latency and small-sample limitations. Source fixes need focused positive contracts. Prompt corrections must address general observed behavior, never encode answers or scorer internals.

Runtime: fresh isolated home and fresh sample projects, owned loopback server/MCP services, no installed UI/process changes. 300 seconds of actual inactivity, poll 2 seconds, concurrency 2. Existing request auditing enforces exact model and streaming; cumulative experiment safety cap 600 requests. Check progress on timed wakes rather than continuous log tailing. Stop only owned processes after settling Tasks and remove only experiment credential copies. No UI modification or visual acceptance is required for this API/checker experiment.

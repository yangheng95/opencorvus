---
title: SDK
description: Type-safe JS / TS client for the OpenCorvus server.
---

OpenCorvus ships the `@opencorvus-ai/sdk` package for TypeScript callers that need a typed client for the REST and SSE API.

Use the SDK when you want to:

- connect to a running `opencorvus serve`
- launch an embedded OpenCorvus server process from another Node/Bun program
- consume generated request/response types from `packages/sdk/openapi.json`

The complete SDK reference is maintained in one place: [JavaScript / TypeScript SDK reference](../reference/sdk/).

For the full route and `operationId` list, use [HTTP API reference](../reference/api/).

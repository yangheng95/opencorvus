---
title: 权限
description: 选择 Full access 或 Ask me，并管理精确范围批准。
---

OpenCorvus 为新任务和直接会话提供一个授权设置：

- **Full access** 是默认模式。需要权限的 Tool、模型上下文协议（Model Context Protocol，MCP）、浏览器、计算机、插件、联网、进程、写入、发布、计划任务和外部服务调用会直接执行，不显示 OpenCorvus 授权询问。
- **Ask me** 是操作员显式选择的模式。需要权限的调用会在执行前暂停。

身份、认证、规范路径、过期运行时、任务归属和数据完整性检查在两个模式下始终生效。工具安装和 Agent 能力分配属于独立控制面，只决定能否提供工具，不代表某次具体调用已经获批。

## Ask me 决定

每个请求会显示提供方、Tool、影响类型、脱敏后的规范参数，以及所属任务或会话。根据影响类型，可以选择：

- **本次允许**：只允许当前精确调用；
- **本任务允许**：在当前任务中复用完全相同的类型化范围；
- **始终允许精确范围**：仅适用于项目级的本地读写、进程和联网读取；
- **拒绝**。

参数、目标、路径、提供方摘要、Tool 或影响类型变化时会产生新请求。破坏性操作、凭据释放和外部副作用不能获得项目级批准。

## 持久记录与恢复

请求、决定、批准复用、撤销和执行结果都会追加到权限账本。设置页可查看生效中的批准和最近记录，也可撤销批准。悬置请求在运行时重启后仍然保留，不会超时，也不会静默切换模式。如果副作用已启动但结果未知，OpenCorvus 会记录未知结果，不会盲目重复执行。

会话首次执行需要授权的调用时会冻结模式；修改设置只影响新工作。

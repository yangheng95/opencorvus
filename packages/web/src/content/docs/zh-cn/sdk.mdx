OpenCorvus 提供 `@opencorvus-ai/sdk` 包，供 TypeScript 调用方访问 REST 与 SSE API。

适合使用 SDK 的场景：

- 连接已经运行的 `opencorvus serve`
- 在另一个 Node/Bun 程序里拉起嵌入式 OpenCorvus server 进程
- 复用从 `packages/sdk/openapi.json` 生成的请求/响应类型

完整 SDK 参考只维护在一个页面：[JavaScript / TypeScript SDK 参考](../reference/sdk/)。

完整路由与 `operationId` 清单见 [HTTP API 参考](../reference/api/)。

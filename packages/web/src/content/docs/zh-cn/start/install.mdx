## 原生安装

```bash
curl -fsSL https://opencorvus.ai/install | bash
opencorvus --version
opencorvus doctor
```

安装器会选择 Windows x64、macOS x64/arm64 或 Linux x64/arm64 原生归档，
并把完整运行包安装到 canonical runtime root 的 `bin` 目录。主程序、Ripgrep、浏览器运行时、
原生模块和 Overlay UI 必须保持在同一目录；OpenCorvus 不会被错误地安装成
缺失依赖的单文件程序。

项目与 worktree 操作需要 Git。Python ≥ 3.9 仅在代码执行和部分 skill 中需要。
Windows 用户请使用 `python`，**不要使用 `python3`**（Store stub 会拦截）。

## 从源码构建

源码构建需要 Bun ≥ 1.3.14 与 Node.js ≥ 22。

```bash
git clone https://github.com/yangheng95/opencorvus.git
cd opencorvus
bun install
bun run package:native-binary
bun packages/opencorvus/src/index.ts doctor
# 完整 bundle 与归档位于 packages/opencorvus/dist/
```

仓库 monorepo 结构：`packages/opencorvus`（核心）、`packages/overlay`（Tauri 桌面端）、`packages/channel-runtime`（多 channel 适配）、`packages/channel-config`（channel 注册表与 schema）。

## 验证安装

```bash
opencorvus doctor
```

`doctor` 子命令会检查依赖、网络、LLM provider 连通性。

## 第一次启动前的配置

推荐先创建一份最小项目配置 `<repo>/.opencorvus/opencorvus.jsonc`：

```jsonc
{
  "model": "openai/gpt-5.5",
}
```

然后设置 API Key（选一个 provider）：

```bash
export DASHSCOPE_API_KEY=sk-...       # 阿里云 DashScope
# 或
export ANTHROPIC_API_KEY=sk-ant-...   # Anthropic
# 或
export OPENAI_API_KEY=sk-...          # OpenAI
```

完整配置见 [OpenCorvus 配置](../../config/)。

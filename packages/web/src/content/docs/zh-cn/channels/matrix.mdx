## 前置

1. 在你的 Homeserver（如 matrix.org 或自建 Synapse）注册一个账号供 Bot 使用。
2. 拿到 Access Token（通过登录 API 或 Element 设置 → Help & About → Advanced）。

## 环境变量

```bash
export MATRIX_HOMESERVER_URL=https://matrix.example.com
export MATRIX_ACCESS_TOKEN=syt_...
export MATRIX_SINCE_TOKEN=          # 可选，断点续传的 sync token
```

## Thread 语义

Matrix 的 `event_id` + `rel_type: m.thread` 作为 thread key；普通消息以 `room_id` 代替。

## 故障排查

- **401 Unrecognised token**：access token 失效，重新登录获取。
- **消息丢失**：`MATRIX_SINCE_TOKEN` 持久化未写入；重启后从最新 sync 开始，中间消息会丢。

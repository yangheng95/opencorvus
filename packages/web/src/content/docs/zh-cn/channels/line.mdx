## 前置

1. 在 [LINE Developers](https://developers.line.biz/) 创建 Provider → Channel（Messaging API）。
2. 获取 **Channel Access Token** 与 **Channel Secret**。
3. Webhook URL：`https://<你的公网>/line`，Use webhook = Enabled。

## 环境变量

```bash
export LINE_CHANNEL_ACCESS_TOKEN=...
export LINE_CHANNEL_SECRET=...
export LINE_WEBHOOK_HOST=0.0.0.0
export LINE_WEBHOOK_PORT=16670
export LINE_WEBHOOK_PATH=/line
```

## Thread 语义

LINE 为 1:1 聊天或群聊；thread key = `userId` 或 `groupId`。

## 故障排查

- **Signature validation failed**：`LINE_CHANNEL_SECRET` 错；签名算法是 HMAC-SHA256。
- **Reply token expired**：此适配器使用 LINE push message 发送任务回复；replyToken 只作为传入 webhook 元数据保留。

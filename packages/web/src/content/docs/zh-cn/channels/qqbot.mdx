---
title: QQ Bot
description: 通过 OpenClaw 官方 channel 插件接入 QQ Bot。
---

OpenCorvus 直接使用已发布的 `@openclaw/qqbot` 实现。平台配置、路由能力和限制见 [OpenClaw 官方 QQ Bot 文档](https://docs.openclaw.ai/channels/qqbot)。

## 环境变量

```bash
export QQBOT_APP_ID=...           # 必填：QQ Bot 应用 ID
export QQBOT_CLIENT_SECRET=...    # 必填：QQ Bot client secret
```

旧的 `qq` adapter 和 `QQ_BOT_*` 环境变量已删除；`qqbot` 是 catalog 与运行时的唯一身份。

title: Environment Variables

---

本页只列出当前源码会读取、且对操作者或集成方有意义的环境变量。构建专用、测试专用、父进程内部注入变量不放入公开 reference。

## 路径与配置

| 变量                                | 用途                                                                                                               | 默认值                                                                                         |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| `OPENCORVUS_HOME`                   | 所有 OpenCorvus 自有目录的绝对 canonical root，包括 bin、cache、config、data、log、state、tmp 和 Overlay/WebView。 | Windows 为 `%LOCALAPPDATA%/opencorvus`；macOS 为 Application Support；其他平台为 XDG data home |
| `OPENCORVUS_CONFIG`                 | 在全局配置之后读取一个显式 config 文件。                                                                           | 未设置                                                                                         |
| `OPENCORVUS_CONFIG_DIR`             | 读取一个本地 OpenCorvus config 目录。                                                                              | 未设置                                                                                         |
| `OPENCORVUS_CONFIG_CONTENT`         | 内联 JSON config，常由 channel runtime 或容器注入。                                                                | 未设置                                                                                         |
| `OPENCORVUS_DISABLE_PROJECT_CONFIG` | 禁用项目配置发现。                                                                                                 | false                                                                                          |
| `OPENCORVUS_PROJECT_DIR`            | `serve` 和 benchmark helper 的默认项目目录。                                                                       | 当前工作目录                                                                                   |

## 运行身份

| 变量                           | 用途                                              | 默认值                   |
| ------------------------------ | ------------------------------------------------- | ------------------------ |
| `OPENCORVUS_CHANNEL`           | user agent 使用的安装/channel 标签。              | `local`                  |
| `OPENCORVUS_CLIENT`            | 运行时行为和 provider header 使用的 client 标签。 | `cli`                    |
| `OPENCORVUS_SERVER_USERNAME`   | HTTP Basic Auth 用户名。                          | `opencorvus`             |
| `OPENCORVUS_SERVER_PASSWORD`   | 对外 server 的 HTTP Basic Auth 密码。             | 未设置                   |
| `OPENCORVUS_SERVER_URL`        | server 和 sidecar 入口导出的 server URL。         | 由启动 server 的进程设置 |
| `OPENCORVUS_PUBLIC_URL`        | 发布 channel attachment 时使用的公网 URL。        | 未设置                   |
| `OPENCORVUS_PUBLIC_URL_SECRET` | 公网 attachment URL 使用的 secret。               | 未设置                   |

## 超时与权限

| 变量                                              | 用途                                     | 默认值               |
| ------------------------------------------------- | ---------------------------------------- | -------------------- |
| `OPENCORVUS_EXPERIMENTAL_BASH_DEFAULT_TIMEOUT_MS` | bash tool call 的默认无活动超时。        | tool 默认            |
| `OPENCORVUS_RUN_STALL_TIMEOUT_MS`                 | `opencorvus run` 的无活动超时。          | 运行时默认           |
| `OPENCORVUS_BROWSER_LAUNCH_TIMEOUT_MS`            | 浏览器启动超时。                         | 运行时默认           |
| `OPENCORVUS_QUESTION_TIMEOUT_MS`                  | 未回复 question interaction 的拒绝超时。 | `300000`             |

## 功能开关

| 变量                                      | 用途                                 |
| ----------------------------------------- | ------------------------------------ |
| `OPENCORVUS_DISABLE_AUTOUPDATE=1`         | 禁用 auto-update。                   |
| `OPENCORVUS_DISABLE_PRUNE=1`              | 禁用 compaction prune。              |
| `OPENCORVUS_DISABLE_AUTOCOMPACT=1`        | 禁用 automatic compaction。          |
| `OPENCORVUS_DISABLE_TERMINAL_TITLE=1`     | 禁用 terminal title 修改。           |
| `OPENCORVUS_DISABLE_LSP_DOWNLOAD=1`       | 禁用 language-server 下载。          |
| `OPENCORVUS_DISABLE_CLAUDE_CODE=1`        | 禁用 Claude Code 集成。              |
| `OPENCORVUS_DISABLE_CLAUDE_CODE_PROMPT=1` | 禁用 Claude Code prompt discovery。  |
| `OPENCORVUS_DISABLE_CLAUDE_CODE_SKILLS=1` | 禁用 Claude Code skill discovery。   |
| `OPENCORVUS_DISABLE_EXTERNAL_SKILLS=1`    | 禁用外部 skill discovery。           |
| `OPENCORVUS_ENABLE_QUESTION_TOOL=1`       | 为非交互 client 启用 question tool。 |
| `OPENCORVUS_ENABLE_EXPERIMENTAL_MODELS=1` | 包含 model catalog 中的 alpha 模型。 |
| `OPENCORVUS_ENABLE_EXA=1`                 | 配置后启用 Exa web search。          |

| `GOOGLE_GENERATIVE_AI_API_KEY` | Google AI provider API key。         |
| `DEEPSEEK_API_KEY`             | DeepSeek provider API key。          |
| `OPENROUTER_API_KEY`           | OpenRouter provider API key。        |
| `DASHSCOPE_API_KEY`            | DashScope provider 共享 key。        |
| `ALIBABA_CODING_PLAN_API_KEY`  | DashScope Coding Plan provider key。 |

## Browser 与 MCP

MCP 是 Model Context Protocol。

| 变量                                        | 用途                                            |
| ------------------------------------------- | ----------------------------------------------- |
| `OPENCORVUS_BROWSER_EXECUTABLE`             | 浏览器 executable 路径。                        |
| `OPENCORVUS_BROWSER_LAUNCH_ARGS`            | browser preview 使用的 JSON array launch args。 |
| `OPENCORVUS_BROWSER_MCP_SOURCE_PACKAGE_DIR` | Browser MCP 的 source package directory。       |
| `OPENCORVUS_BROWSER_MCP_PACKAGED=1`         | 标记 Browser MCP 为 packaged。                  |
| `OPENCORVUS_BROWSER_MCP_NODE`               | Browser MCP sidecar 使用的 Node executable。    |

## Channels 与语音识别

STT 是 speech-to-text（语音转文字）。

| 变量                                           | 用途                                           |
| ---------------------------------------------- | ---------------------------------------------- |
| `OPENCORVUS_CHANNEL_SERVER_URL`                | channel runtime 使用的后端 URL。               |
| `OPENCORVUS_CHANNEL_PERMISSION_PROFILE`        | channel permission profile。                   |
| `OPENCORVUS_CHANNEL_PROTOCOL=1`                | 为支持的平台启用 channel protocol mode。       |
| `OPENCORVUS_SHARED_SESSION_MODE=1`             | 启用 shared session mode。                     |
| `OPENCORVUS_SHARED_SESSION_FILE`               | shared session 文件路径。                      |
| `OPENCORVUS_MIRROR_STDOUT=1`                   | 将 channel-runtime stdout 镜像到上层。         |
| `OPENCORVUS_MONITOR_DIFF_THRESHOLD`            | visual monitor 差异阈值。                      |
| `STT_PROVIDER`                                 | 单一 speech-to-text provider。                 |
| `STT_LANGUAGE`                                 | 语音识别语言。                                 |
| `GROQ_API_KEY`                                 | Groq speech-to-text key。                      |
| `STT_GROQ_MODEL` / `STT_GROQ_BASE_URL`         | Groq speech-to-text 模型与 base URL。          |
| `STT_OPENAI_MODEL` / `STT_OPENAI_BASE_URL`     | OpenAI Whisper 模型与 base URL。               |
| `DEEPGRAM_API_KEY`                             | Deepgram key。                                 |
| `STT_DEEPGRAM_MODEL` / `STT_DEEPGRAM_BASE_URL` | Deepgram 模型与 base URL。                     |
| `GOOGLE_API_KEY`                               | Google Gemini speech-to-text key。             |
| `STT_GOOGLE_MODEL` / `STT_GOOGLE_BASE_URL`     | Google Gemini speech-to-text 模型与 base URL。 |
| `STT_LOCAL_COMMAND`                            | 本地 speech-to-text 命令。                     |

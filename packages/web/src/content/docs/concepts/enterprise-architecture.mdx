## Review Scope

The explorer intentionally excludes retired planner/deliver/evaluation-table narratives. Current durable process evidence is represented through `engine_artifact`, task snapshots, explicit `dispatch_agent` calls to exact projected identities, task-scoped browser preview evidence, visual QA, and Integrity attempts.

For the compact architecture narrative, see [Architecture](./architecture.md). For the table-level model, see [Task / Delivery Slice data model](./delivery-slice-task.md).

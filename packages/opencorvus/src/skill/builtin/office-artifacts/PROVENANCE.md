# Provenance

This umbrella Skill is an OpenCorvus clean-room implementation based on public behavior
and architecture documentation.

Sources consulted:

- OfficeCLI repository, command help, wiki, Apache-2.0 license, and
  `v1.0.143` release metadata:
  <https://github.com/iOfficeAI/OfficeCLI>
- Agent Skills specification:
  <https://github.com/agentskills/agentskills>
- Microsoft Agent Framework Skills:
  <https://learn.microsoft.com/en-us/agent-framework/agents/skills>
- OpenAI plugin and Skill architecture:
  <https://developers.openai.com/plugins/concepts/plugins>
  and <https://developers.openai.com/plugins/build/skills>

The workflow uses general ideas such as progressive disclosure, typed tools,
fresh rendering, and complete visual inspection. No proprietary OpenAI or
Anthropic Skill text, template, runtime, or asset is copied or distributed.

# Phase-one presentation authoring

## Start with the story

- Give each slide one job and one audience-facing takeaway.
- Use a short title that states the point, not a generic section label.
- Prefer a clear sequence: context, evidence, implication, decision, next step.
- Keep the opening and closing slides intentionally sparse.
- Use tables or charts only when they make comparison or magnitude materially
  easier to understand.

## Layout

- Use 16:9. This first production slice does not support another aspect ratio.
- Keep a consistent margin, type scale, color system, and alignment grid.
- Use a small number of purposeful shapes. Avoid decorative density.
- Keep paragraph copy short enough to read from presentation distance.
- Use one native chart per quantitative claim when the data supports it.
- Use supplied image attachments only when they add evidence or meaning; set
  useful alt text and avoid distorted aspect ratios.

## Source discipline

- Use only content, claims, and images available in the request, project,
  attachments, connected tools, or cited research.
- Do not invent metrics, customer quotes, logos, or source claims.
- Put concise source notes on the slide or in notes when provenance matters.
- Separate an evidence-backed claim from an inference or recommendation.

## Typed authoring input

- Supply a safe output basename ending in `.pptx`.
- Supply complete ordered slides in one authoring call.
- Use typed text, shape, picture, and chart elements only.
- Reference pictures through canonical attachment URLs; never pass a local path
  or remote URL.
- Keep all positions inside the declared slide bounds.

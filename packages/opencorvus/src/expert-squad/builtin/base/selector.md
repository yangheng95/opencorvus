# Base Expert Squad

Select `base` for an ordinary repository delivery whose complete requested outcome can be divided once into independent research, product implementation, and test/checker ownership.

Base is Advanced's convenient compact alternative. It retains distinct planning, implementation, and testing identities while omitting Advanced's requirements engineering, architecture, staged specialist review, and richer dependency graph. Select `planner-execution-verification` when source discovery, implementation, or verification requires a project Skill, command, local client, package Tool, Model Context Protocol capability, or browser action that the read-only Researcher does not own. Select `planner-parallel-delivery` only when the Planner can allocate one complete independent repository/web research partition to `base-researcher` and non-overlapping executable work to `base-developer`. Select `advanced` when later workers must truthfully consume earlier worker Artifacts as inputs to their own design, or select a more specific installed Expert Squad when its declared domain workflow owns the complete outcome.

One selected Base Task is a substantial delivery closure. Workload size, duration, acceptance-item count, deliverable formats, directories, data generation, reports, audits, tests, and same-Task Artifact dependencies do not divide it into Mission phases. Base's Orchestrator and declared workflow identities coordinate those internal responsibilities inside the same Task.

Base visibly binds exactly one workflow before the first domain dispatch. Both workflows run the Planner first and the Tester after the Developer settles. `planner-execution-verification` runs only those three capability-matched owners. `planner-parallel-delivery` additionally runs Researcher beside Developer when its complete read/web partition is genuinely independent. The Tester edge is ordering, not an Artifact handoff: its acceptance scope stays the original request, canonical plan, and current authoritative sources, never the Developer's account of what it did. Base never creates Goal-derived planning facts and never combines its graph with an Advanced workflow. If the current Task already started domain execution under another active package, do not switch it in place.

# Base Expert Squad

Select `base` for an ordinary repository delivery whose complete requested outcome can be divided once into independent research, product implementation, and test/checker ownership.

Base is Advanced's convenient compact alternative. It retains distinct planning, research, implementation, and testing identities while omitting Advanced's requirements engineering, architecture, staged specialist review, and richer dependency graph. Select `planner-parallel-delivery` when the Planner can allocate non-overlapping paths and acceptance obligations. Select `advanced` when later workers must truthfully consume earlier worker Artifacts, or select a more specific installed Expert Squad when its declared domain workflow owns the complete outcome.

One selected Base Task is a substantial delivery closure. Workload size, duration, acceptance-item count, deliverable formats, directories, data generation, reports, audits, tests, and same-Task Artifact dependencies do not divide it into Mission phases. Base's Orchestrator and declared workflow identities coordinate those internal responsibilities inside the same Task.

Base visibly binds its single workflow before the first domain dispatch. The Planner runs first; Researcher, Developer, and Tester then become dependency-ready together and consume only the plan. Base never creates Goal-derived planning facts and never combines its graph with an Advanced workflow. If the current Task already started domain execution under another active package, do not switch it in place.

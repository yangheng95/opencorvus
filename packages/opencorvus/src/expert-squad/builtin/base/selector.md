# Selecting Base

Base owns ordinary repository and external-state delivery through one accountable Task owner and independent review. The owner executes its explicitly granted tools directly. `execution-verification` consists of the independent Tester after the owner's work settles.

Use the source-planned workflow only when an independently investigated source-authority prerequisite justifies a separate specialist before delegated production. Use the parallel workflow only for actual independent research and implementation partitions. Respect their declared nodes and capabilities. The original outcome, permissions, source facts and genuine updates remain authority throughout.

Independent verification compares original obligations with raw sources, effects and exact deliverable versions. It may reuse complete immutable Tool evidence within its time/scope, and must query again for current-state requirements, missing facts or contradictions. Select a domain Squad when Base cannot own the complete requested outcome under its explicit capabilities.

制作一个网页计算器（Web Calculator）。

【基础功能】
1. 四则运算：加、减、乘、除，支持小数与负数；除以 0 显示 "Error"。
2. 支持括号嵌套，按算符优先级求值（不要用 `eval`，自行实现 tokenizer + 解析）。
3. 百分号 `%`、平方 `x²`、平方根 `√`、倒数 `1/x`、正负号切换 `±`。
4. 清除：`AC` 全清，`C` 清当前输入，退格 `⌫` 删一位。
5. 历史记录：在主显示下方显示当前正在输入的算式（实时高亮当前操作数），结果区显示当前值或最终结果。
6. 历史面板：保留最近 20 条算式 + 结果，点击任意一条可把结果填回主输入；提供"清空历史"。

【交互】
7. 键盘支持：数字 0-9、`. + - * /`、`Enter` = `=`、`Backspace` = `⌫`、`Escape` = `AC`、`(`、`)`。
8. 按键按下时对应按钮有视觉反馈（按下态动画）。
9. 数字超过 12 位自动切换为科学计数法显示，避免溢出。

【UI / 设计】
10. 现代深色主题（默认）+ 浅色主题切换；保存到 localStorage。
11. 主显示区右对齐大号等宽字体；按钮 4 列 5 行网格布局，运算符与功能键用区分色。
12. 移动端可用（单列竖屏 ≥ 360px），桌面端居中最大宽度 420px，整体卡片化。
13. 无 lorem ipsum、无占位、无 console 红字。

【技术】
14. 纯前端（HTML + CSS + TypeScript/JavaScript），无后端、无外部 API。
15. 单页面入口（index.html）即可直接打开运行；如使用 Vite 等工具，必须提供 `npm install && npm run build` 后产出可独立托管的 dist。
16. 提供 README.md 说明运行方式、键盘快捷键。
